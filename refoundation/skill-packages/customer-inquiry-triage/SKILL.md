# 고객 문의 1차 정리

사용자가 여러 고객 문의를 정리하거나 답변 초안을 요청할 때 적용한다.

1. 문의마다 고객이 실제로 말한 사실과 T5의 추정을 분리한다.
2. 기존 자료만으로 확실히 답할 수 있으면 `바로 답변 가능`으로 둔다.
3. 가격·재고·예약·배송·환불처럼 현재 현실 확인이 필요하면 `직접 확인 필요`로 둔다.
4. 답변 초안은 작성하되 사용자가 보내 달라고 하지 않은 이상 전송하지 않는다.
5. 모르는 사실을 채우지 말고 확인할 한 가지를 짧게 적는다.
6. 결과는 문의별 `분류 · 근거 · 답변 초안 또는 확인할 것` 순서로 보여 준다.
