# GPAO-T5 설치하고 쓰기

팀 내부 1차 설치본 안내입니다. 터미널을 몰라도 됩니다 — **딱 한 곳, 제거할 때만** 필요하고
그 자리는 아래에 그대로 적어 뒀습니다.

- 파일: `GPAO-T5-0.1.0-arm64.pkg`
- 버전: 0.1.0 (팀 내부 1차)

## 0. 먼저 확인할 것 하나

**Apple Silicon Mac 에서만 돌아갑니다.** M1 이후 맥이면 됩니다.

확인하는 법: 화면 왼쪽 위 사과 → **이 Mac에 관하여** → 칩 항목에 `Apple M...` 이 보이면 맞습니다.
`Intel` 이라고 적혀 있으면 **이 설치본은 안 됩니다.** 설치는 되는 것처럼 보여도 실행되지 않습니다.
(Intel 용은 다음 산출물에서 다룹니다.)

## 1. 설치

1. 받은 `GPAO-T5-0.1.0-arm64.pkg` 를 **두 번 클릭**합니다.
2. 나오는 대로 **계속 → 설치**를 누릅니다.
3. 맥 **관리자 비밀번호**를 한 번 물어봅니다. 프로그램을 `응용 프로그램` 폴더에 넣기 때문입니다.
4. 끝나면 **알아서 켜지고 브라우저 화면이 열립니다.** 따로 실행할 것이 없습니다.

Apple 에 등록·공증된 설치본이라 "확인되지 않은 개발자" 경고는 나오지 않습니다.
혹시 그런 경고가 뜬다면 파일이 중간에 손상된 것이니 다시 받으세요.

## 2. 처음 화면 — 모델 하나 연결하기

첫 실행에서 오른쪽에 설정이 열리고 이렇게 뜹니다.

> **먼저 쓸 모델을 연결해요.** 하나만 연결하면 바로 대화를 시작할 수 있어요.

두 가지 길이 있습니다.

**① API 키로 연결 (권장)**
- 왼쪽 목록에서 쓸 곳을 고릅니다 — `BEAI` · `Gemini` · `OpenAI` · `Claude` · `호환 서버(직접 입력)`
- 오른쪽 칸에 **API 키**를 붙여 넣고 **연결**을 누릅니다.
- `모델(비우면 기본)` 칸은 비워 두면 됩니다. 특정 모델을 쓰고 싶을 때만 적습니다.

**② ChatGPT 계정으로 연결**
- 버튼이 따로 있습니다. 다만 화면에도 적혀 있듯 **공식 지원 방식이 아니라서 막히면 연결이 끊길 수 있습니다.**
  업무에 계속 쓸 거라면 ①을 권합니다.

**"나중에 할게요"** 를 눌러도 되지만, 그러면 대화가 되지 않습니다.
모델이 없는 동안 T5 는 "내장 안내 모드"로만 답합니다. 화면 아래에 `연결된 모델 없음` 이라고 계속 보입니다.
연결하고 나면 그 자리가 모델 이름과 `준비됨` 으로 바뀝니다.

API 키는 이 컴퓨터 안에만 저장됩니다. 화면 어디에도 다시 나오지 않습니다.

## 3. 평소에 쓰는 법

| 하고 싶은 것 | 방법 |
|---|---|
| 열기 | Dock 의 **GPAO-T5** 아이콘을 누릅니다. 화면이 열립니다. |
| 끄기 | T5 가 앞에 있을 때 **⌘Q**. 또는 Dock 아이콘 우클릭 → 종료. |
| 다시 켜기 | 아이콘을 다시 누릅니다. |
| 껐다 켜도 되나 | 됩니다. 대화와 기억은 그대로 남습니다. |

**맥에 로그인하면 T5 가 알아서 켜져 있습니다.** 이때는 브라우저를 띄우지 않습니다 —
갑자기 창이 튀어나오지 않게 한 것입니다. 쓰고 싶을 때 Dock 아이콘을 누르면 화면이 열립니다.

아이콘을 여러 번 눌러도 T5 가 여러 개 켜지지는 않습니다.
다만 **누를 때마다 브라우저에 탭이 하나씩 새로 열립니다**(같은 화면입니다). 탭이 쌓이면 닫으시면 됩니다.

## 4. "연결 위치가 바뀌었어요" 라는 말이 나오면

다른 프로그램이 T5 가 쓰는 자리를 먼저 쓰고 있을 때 나옵니다. T5 는 **알아서 다른 자리로 옮겨서 켜집니다.**
할 일이 없습니다. 쓰던 대로 쓰시면 되고, 대화·기억·자동 시작 모두 그대로입니다.

## 5. 안전에 대해 — 있는 그대로

- T5 는 **이 컴퓨터 안에서만** 열립니다. 같은 사무실 다른 컴퓨터에서 접속할 수 없습니다.
- 인터넷에서 열어 둔 **다른 웹페이지가 T5 를 몰래 부를 수 없습니다.** 세 겹으로 막아 뒀습니다.
- 다만 **같은 맥 계정으로 도는 다른 프로그램까지 막지는 못합니다.** 그건 계정을 나눠야 되는 일이라
  이 버전에서는 하지 않았습니다. 남이 쓰는 계정에 T5 를 깔지 마세요.
- 대화와 기억은 **이 맥 안에만** 있습니다. 위치는 `~/.local/state/gpao-t5/sessions` 입니다.
  백업하려면 이 폴더를 복사하면 됩니다.

## 6. 지우기

앱만 휴지통에 넣지 마세요. **로그인 자동 시작 등록이 남아** 켜질 때마다 없는 프로그램을 찾습니다.

터미널(응용 프로그램 → 유틸리티 → 터미널)에서 아래 한 줄을 붙여 넣고 Enter:

```bash
/Applications/GPAO-T5.app/Contents/Resources/uninstall.sh
```

`GPAO-T5 을 제거했어요. 대화와 기억은 그대로 있어요.` 가 나오면 끝입니다.
앱·자동 시작 등록·켜져 있던 프로그램이 함께 사라집니다.

**대화와 기억은 지워지지 않습니다.** 다시 설치하면 그대로 이어집니다.
기억까지 지우고 싶으면 `~/.local/state/gpao-t5` 폴더를 직접 지우세요 — 되돌릴 수 없습니다.

로그인할 때 자동으로 켜지는 것만 끄고 싶다면(프로그램은 남기고):

```bash
launchctl bootout gui/$(id -u)/kr.co.gpao.t5.agent; rm -f ~/Library/LaunchAgents/kr.co.gpao.t5.agent.plist
```

> 터미널 없이 지우는 길은 아직 없습니다. 다음 산출물에서 만듭니다.

## 7. 잘 안 될 때

| 증상 | 먼저 해 볼 것 |
|---|---|
| 설치했는데 아무 것도 안 뜬다 | Dock 에 GPAO-T5 아이콘이 있는지 보고 눌러 보세요. |
| 대화를 걸었는데 답이 이상하다 | 화면 아래가 `연결된 모델 없음` 이면 §2 로 돌아가 모델을 연결하세요. |
| 화면이 멈춘 것 같다 | **⌘Q** 로 끈 다음 아이콘을 다시 누르세요. 대화는 남습니다. |
| 그래도 안 된다 | 화면에 나온 **문장 그대로** 알려 주세요. 오류 번호보다 그 문장이 원인을 훨씬 빨리 찾아 줍니다. |
