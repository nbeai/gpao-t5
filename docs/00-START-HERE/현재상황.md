### 1-A. ⚠ 게이트가 막혀 있다 — **자[尺]가 크기와 함께 안 자란다**

```
✗ 벽시계 35.4s > 30s
✓ CPU 81.0s (기준선 81.4s)     ← 여유 0.5%. 이쪽도 선에 걸려 있다
```

**검사가 느려진 것이 아니다.**

```
CPU 상한     max(40, 검사수 × 0.025)   → 검사가 늘면 같이 는다
벽시계 상한   **30초 고정**             → 검사가 늘면 **반드시** 터진다
```

`gate.mjs` 주석이 이 선의 목적을 이미 적어 뒀다 — *"CPU 는 일한 양의 폭주를, 벽시계는
**기다림**을 막는다."* 잠든 검사(`sleep 30`)는 CPU 를 안 쓰기 때문이다.
**그런데 지금 모양은 기다림이 아니라 크기를 재고 있다.**

#### 오너 결정 2026-08-07 — **숫자를 올리지 않고 자의 모양을 바꾼다**

목적(잠든 검사 잡기)은 그대로, 크기와 무관한 축으로 옮긴다.

```
검사는 --test-concurrency=3 로 돈다. 일한 양이 CPU 라면 이상적인 벽시계는 CPU ÷ 3 이다.
그 차이가 곧 **아무도 일하지 않은 시간**이다.

    유휴 = 벽시계 − CPU ÷ 동시성

지금 실측          35.4 − 81.0÷3 = **8.4s**
sleep 30 이 섞이면  유휴가 30s 대로 튄다      ← 목적 그대로 잡힌다
검사가 두 배로 늘면 CPU·벽시계가 같이 늘어 **유휴는 그대로**  ← 크기와 무관
```

**개발 라인이 받는다. 규격은 이것이다:**

```
1  gate.mjs 의 벽시계 판정을 **유휴 판정**으로 바꾼다.
   동시성은 package.json 의 --test-concurrency 에서 **읽는다**(숫자를 박지 않는다)
2  상한은 **실측으로 교정한다**(scripts/calibrate-gate.mjs).
   같은 커밋을 부하 있는 상태·없는 상태로 여러 번 재고 그 범위를 근거로 적는다
3  **반대시험이 없으면 이 변경은 장식이다** — 일부러 잠드는 검사를 넣고 빨개지는지 본다
4  gate-baseline.json 은 자동 갱신하지 않는다(§17 그대로)
```

**⚠ 닫히기 전에는 게이트 통과를 봉인 근거로 쓰지 않는다.**

#### 닫혔다 (구현 라인 2026-08-08) — 그리고 CPU 축의 새 사실 하나

규격 넷 그대로 구현됐다(`scripts/gate-idle.mjs` · 반대시험은 단위 6건 + 실계 1회 —
일부러 31초 잠드는 검사를 심으니 **유휴 36.0s 로 빨개졌고**, 걷어내니 초록).
실측 유휴 6.2~9.7s(부하 유무 무관) · 상한 20s.

**남은 관측 — CPU 축은 전원 상태에 뒤집힌다.** 같은 트리·같은 날:

```
AC 전원              CPU 41.6~41.7s     ← 여유 두 배
배터리 + 저전력 모드    CPU 82.4~93.0s     ← 선(81.95s)을 넘는다
```

옛 주석의 *"CPU 는 부하에도 ±3%"* 는 **전원 상태가 같을 때만** 참이다. 저전력에서는 같은
일이 효율코어에서 돌아 CPU 시간이 두 배로 찍힌다. 선을 옮길지는 오너 결정 —
그 전까지 게이트는 **AC 전원에서 돌린다**(측정 조건으로 취급).

## 6. 가장 중요한 열린 구멍 — **오너 판단**

> **되돌릴 수 있는 대량 이동은 승인 카드 없이 실행된다.**

헌장이 그렇게 정했고 그 자체는 옳다. 문제는 **짧은 발화 하나가 수백 개를 옮기는 실행으로
이어지고 사용자가 막을 자리가 없다**는 것이다. 실제로 났다 — *"아이기스"* 한 단어에 파일 443개.
되돌렸고 손실 0이지만 **카드는 한 번도 안 떴다.**

막는 방법이 마찰을 늘리는 쪽이라 **오너 판단이 먼저다.**

> **PM 추천안(2026-08-07 · 전임 PM 동의):** 카드를 새로 만들지 않고, 실행 직후 표면에
> *"방금 N개를 옮겼어요 — 한 번에 되돌리기"* 한 줄을 둔다. 승인 마찰 0 유지, 설 자리 제공.
> **조건 하나 — 그 줄은 되돌리기가 실제로 되는 상태일 때만 뜬다.** 뜨는데 안 되돌아가면
> 더 나쁘다. 이 조건을 봉인(회귀)에 넣는다. **오너 확정 대기.**
