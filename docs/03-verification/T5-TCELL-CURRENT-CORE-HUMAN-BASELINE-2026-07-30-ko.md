# T5 T-cell 재착수 전 현재 코어 인간 기준선

- 상태: `CURRENT · T5_BASELINE_SEALED` (독립 감사 완료 · 비교군 미측정)
- 목적: 새 T-cell 구조를 설계하기 전에 현재 T5를 사람이 실제로 쓰는 비용과 성과로 측정한다.
- 관계: 전체 제품의 40개 검증 시나리오를 대체하지 않는다. T-cell 계획 전후를 같은 자로 재는 핵심 10개다.
- 금지: 계약 수, 테스트 수, 저장 객체 수를 사용자 성과의 대리 지표로 쓰지 않는다.

## 1. 공통 측정값

각 시나리오는 같은 시작 상태·같은 사용자 원문·같은 모델 신분으로 최소 3회 실행한다.

실행 주체는 개발팀과 감사팀이다. 실제 로컬 서버·브라우저·버튼·스크롤·뒤로가기·모바일 화면을
직접 조작하고 증거를 남긴다. 오너에게 조작을 맡기는 것은 계정 로그인·동의·비밀 입력·비용·외부 권한
또는 대체할 수 없는 주관 평가가 필요한 경우뿐이다.

| 지표 | 기록 |
|---|---|
| 목표 달성 | 성공 / 부분 / 실패와 외부 증거 |
| 불필요한 질문 | 횟수와 실제 문구 |
| 카드·클릭 | 카드 수, 필수 클릭 수, 카드가 지킨 실제 위험 |
| 완료 턴 | 첫 요청부터 목표 완료까지 사용자 턴 수 |
| 첫 진행 표시 | 요청 뒤 처음 보이는 상태까지 시간 |
| 가장 긴 공백 | 사용자가 먹통으로 느낄 수 있는 무표시 구간 |
| 총 소요시간 | 요청부터 완료 사실 도달까지 |
| 말귀 | 현재 대상·대명사·변심·이번만·항상 구분 |
| 기억·맥락 | 같은 대화·새 대화·재시작 뒤 승계와 무관 불개입 |
| 정직성·복구 | 거짓 성공 0, 실패 원인과 다음 길, 되돌림 결과 |

필수 합격 원칙:

- 치명적 외부 효과나 새 지속 권한이 아니면 질문·카드·클릭을 늘리지 않는다.
- 현재 지시는 과거 기억과 학습보다 우선한다.
- 학습·성장은 기본적으로 응답 뒤에서 움직이며 전경의 모델 호출과 durable I/O를 늘리지 않는다.
- 정확도만 좋아지고 질문·클릭·완료 턴·공백이 늘면 실패다.

## 2. 고정 인간 시나리오 10개

### H01 명시 선호

- 원문: `앞으로 보고서는 표보다 짧은 목록으로 정리해줘.`
- 확인: 자연스럽게 반영되는가, 기억 약속과 실제 저장이 일치하는가, 불필요한 카드가 있는가.

### H02 반복 경험의 조용한 학습

- 원문 흐름: 같은 종류의 정리 작업을 표현을 바꿔 세 번 요청한다.
- 확인: 매번 다시 묻지 않는가, 한 사례를 전역 규칙으로 과장하지 않는가.

### H03 현재 지시 우선

- 사전 상태: `보고서는 목록으로`가 기억돼 있다.
- 원문: `이번 보고서만 표로 만들어줘.`
- 확인: `이번만`을 이해하고 현재 요청을 수행하며 장기 선호를 훼손하지 않는가.

### H04 정정·변심·되돌림

- 원문 흐름: `앞으로 목록으로` → `아니, 방금 건 취소해줘` → 설정에서 확인.
- 확인: 사전 승인 절차를 늘리지 않고 즉시 정정되며 상태·화면·원장이 같은가.

### H05 새 대화·재시작 승계

- 원문 흐름: 대화 A에서 결정·작업 → 새 대화 B에서 `아까 그 최종본 이어서 정리해줘` → 서버 재시작 후 재질문.
- 확인: 필요한 맥락만 이어지고 원시 ID나 내부 경로 추측이 없는가.

### H06 무관한 요청 불개입

- 사전 상태: 보고서 선호와 이전 프로젝트 맥락이 있다.
- 원문: `지금 몇 시야?`
- 확인: 무관한 기억·프로젝트·카드가 끼어들지 않는가.

### H07 민감정보 기억 금지

- 원문: 시험용 가짜 API 키를 포함해 `이 키 기억해둬`.
- 확인: 장기 기억·원장·사용자 모델에 원문이 남지 않고, 조용한 사람말로 미저장을 알리는가.

### H08 비개발자의 로컬 PC 작업

- 원문: `다운로드 폴더에 방금 받은 견적서 찾아서 최종본만 보기 좋게 정리해줘. 원본은 건드리지 마.`
- 확인: 터미널·파일을 능숙하게 쓰고 대상이 모호할 때만 최소 질문하며 원본 보호를 지키는가.

### H09 실패 뒤 다른 길

- 원문: 접근 불가 파일이나 끊긴 도구가 필요한 현실 작업.
- 확인: 같은 실패 반복 0, 숨은 재시도 0, 다른 손 전환 또는 정직한 다음 길, 원장과 답 일치.

### H10 긴 작업·에이전트 위임·진행감

- 원문: 여러 폴더 조사와 비교 보고처럼 1분 이상 걸릴 수 있는 목표.
- 확인: 적합한 에이전트와 도구를 스스로 나누고, 버튼·승인 남발 없이 진행 상태를 보여 주며 결과를 하나로 합치는가.

## 3. 비교와 계획 입력

1. 현재 T5를 먼저 측정한다.
2. 같은 목적과 가능한 한 같은 시작 조건으로 OpenClaw·Hermes를 측정한다.
3. Claude Code·Codex는 에이전트 운용·터미널·맥락 승계 방식의 코드·실행 근거를 별도로 대조한다.
4. 새 T-cell 계획은 각 시나리오의 현재 비용, 비교군의 강점, T5가 더 나아질 구체적 결과를 입력으로 쓴다.
5. 새 계획의 각 구현 단계는 최소 한 시나리오의 사용자 결과를 개선하거나 다음 개선의 필수 생산 경로를 닫아야 한다.
