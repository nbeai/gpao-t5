# S4 결과 — 집이 생겼다. 사용자가 고치면 T5 가 달라진다

2026-08-05 · 라이브 실모델 `gpt-5.1` · 격리 증명 PASS

## 닫는 문장

집(`~/GPAO-T5/지침.md`)에 이렇게 적었다.

```
- **답은 반드시 두 문장 이내로.** 목록·번호 매기기 금지. 길게 쓰면 안 읽는다.
- 말끝은 "~합니다"로 맺어라.
```

같은 질문(`파일 정리는 어떻게 하는 게 좋아?`)의 답:

| | 답 |
|---|---|
| **전** | **1,123자** · 번호 매긴 목록 3단 · 반말 |
| **후** | **197자** · 정확히 두 문장 · 전부 "~합니다" |

**사용자가 자기 컴퓨터의 파일 하나를 고쳤더니 T5 의 행동이 바뀌었다.**
코드를 건드리지 않았고, T5 화면에서 설정한 것도 아니다.

## 무엇이 없었나

T5 가 어떻게 행동할지는 전부 `judgmentCharter()` 에 박혀 있었고 **사용자는 한 글자도 못 고쳤다.**
비교군 넷(OpenClaw·Hermes·Claude Code·Codex)은 전부 이걸 파일로 준다.
그리고 `SOUL.md`·`CAPABILITIES.md` 는 `~/.local/state/gpao-t5/sessions/` 에 있었다 —
XDG 관례상 **상태 디렉터리**이지 사용자가 열어 볼 자리가 아니다.

## 무엇을 세웠나

**집** = `~/GPAO-T5/`(이미 파일 손의 첫째 뿌리이고 사용자에게 "작업 폴더"로 불린다).
**설정·상태** = `~/.local/state/gpao-t5/`(자격·세션·열쇠·원장) — 그대로 둔다.

| 파일 | 역할 | 수명 |
|---|---|---|
| `지침.md` | 이렇게 일해 줘 | **매 세션** · 안정 구역 |
| `사용자.md` | 나에 대해 | **매 세션** · 안정 구역 |

**이름을 복제하지 않았다** — `AGENTS.md` 를 쓸 이유가 없다(계획 §5). 한국 사용자가 파인더로
열어 고치는 파일이므로 우리말 이름을 쓴다.

## 규율 넷

1. **씨앗은 한 번만.** 이미 있으면 절대 덮지 않는다 — 집은 사용자의 것이다.
2. **예산이 있다.** 파일당 4,000자 · 전체 6,000자. 매 세션 실리는 자리에 예산이 없으면
   대화 이력이 밀려난다(불변식 B). OpenClaw 의 20,000/60,000 을 흉내 내지 않았다 —
   **흡수할 것은 숫자가 아니라 "예산을 건다"는 원리다.**
3. **조용히 자르지 않는다.** 넘치면 몇 자를 줄였는지 말한다.
4. **자리 표식을 붙인다.** `[사용자가 집에 적어 둔 지침 — 지금 요청과 부딪히면 지금 요청이 우선한다]`
   이건 런타임이 확인한 사실이 아니라 **사용자가 미리 적어 둔 뜻**이다. 섞이면 모델이 오해한다.
5. **사용자 메시지에는 안 들어간다**(S1 계약). 안정 구역이라 캐시에 얹힌다(불변식 A).

접근이 열리면 그건 **파일 경계를 문서로 뚫는 것**이다. 경계 변경은 그 자체로 판단이 필요하다
