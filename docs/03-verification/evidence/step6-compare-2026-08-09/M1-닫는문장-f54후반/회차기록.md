원장으로 확정했다. 새 그물이 **한 번도 물지 않았다**:
```
라이브 프로브(같은 조건 1회)   exitNetDiagnostic = null   ← 그물 미발화
같은 답·같은 영수증으로 단위 호출  일치:false · "화면 자리는 봤고 **파일 자리는 안 봤다**:
                                Desktop · GPAO-T5 …"      ← 그물 자체는 정상
```
원인: 출구검증에 넘긴 `자리종류.파일` 이 **`ctx.workingState.places`** 였는데, 그건 **이전
턴의 상태**다. 새 세션 첫 턴에는 비어 있어 `안본종류`가 null 이 되고 갈래를 아예 안 탄다.
화면 자리는 턴 머리에서 관측해 `ctx` 에 담아 뒀는데(전반 수리), **파일 자리는 같은 처리를
안 했다** — 대칭을 안 맞춘 내 실수다.

즉 **수리가 시험대에 오르지도 못했다.** 이 회차의 0/3 을 모델의 3회째 멈춤으로 세면
잘못된 판정을 부른다 — 재현이 아니라 미측정에 가깝다(PM 판정 요청 사항).

## 새 구조 사실 — 되돌림 경로는 손이 없다
`출구검증`의 되돌림은 **`answerOnly: true`** 다(설계 주석: *"지금 필요한 것은 새 행동이
아니라 방금 한 일을 정직하게 말하는 것"* — 정직 계열 그물에는 맞다). 그래서 이 그물의
되부름 문장 *"그 자리도 **보거나**, 안 봤다는 것을 밝힌다"* 중 **"보거나"는 구조적으로
불가능하다** — 모델이 손을 쥐고 있지 않다. 남은 길은 "밝히거나" 하나인데 라이브 2표본에서
모델이 그 길을 안 골랐다.

이 계열의 선례: 쓴숫자대조는 같은 이유로 출구가 아니라 **실물이 생기는 영수증에** 사실을
실었다(*"출구 되부름은 손이 없어 실물을 못 고친다"* — 그 머리말 그대로).
