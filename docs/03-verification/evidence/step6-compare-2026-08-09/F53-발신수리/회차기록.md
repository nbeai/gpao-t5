# 방 열기 뚫림 · 입력 성립 · 전송은 미확인 (2026-08-09 오너 창 · "니가 눌러" 지시)

## 뚫린 것 — **방 선택**(두 달 막혔던 자리)
```
get_window_state{max_elements:60, max_depth:12}   ← 깊이 제한이 핵심
  → 요소 11개 · 그중 ★ {"label":"넵 명심하겠습니다","token":"s0000001c:5"}
double_click{element_token:"s0000001c:5"} → 창 4806 "n.BEAI 사일런트서비스" 열림 · 오대상 0
```
**정체 확정**: 그동안 label 로 못 짚은 이유는 이름이 없어서가 아니라 **AX 트리 전체 걷기가
20초 타임아웃**(드라이버 원문: *"AX tree walk for pid=1048 timed out after 20 s … re-call
with a depth-limited scan"*)이라 요소가 0~18개로만 보였기 때문이다. 깊이 제한을 주면 산다.
방 이름 자체는 목록에 없고 **그 방의 마지막 메시지**가 그 행의 신분이다.

## 성립한 것 — 입력(제품 턴)
방이 열린 상태에서 제품 턴 실행: 승인 카드 뜸(승인 전 실행 0) → 승인 뒤 실행 →
**입력창에 허가 문구가 그대로 들어감**(캡처 `후-실물-방.jpg` — 전송 버튼 활성).
모델의 답도 정직했다: *"입력만 시도한 상태라 실제 전송 여부는 확인해 주세요."*

## 전송 — 눌렀으나 **미확인**
방 창은 AX 요소 0(8/6 기록과 같다: *"카톡은 AX 요소가 0인 창"*), zoom 도 실패해 좌표를 못
세웠다. 그래서 **Enter**(foreground)로 보냈다:
```
press_key{key:"Return", window_id:4806, delivery_mode:"foreground"}
  → { delivery: foreground, effect: "unverifiable", route: "global_input" }
```
그 뒤 확인이 **전부 실패**: zoom(4806·52) 둘 다 ScreenCaptureKit 캡처 오류 ·
get_window_state 둘 다 요소 0. 창 목록만 정상 응답.
→ **전송됐는지 기계로 확정하지 못했다. "보냈다"고 적지 않는다**(절대 게이트: 거짓 성공 금지).
오너 화면에서 그 방의 마지막 메시지를 보시면 즉시 갈린다.
