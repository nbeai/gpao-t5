## 원인 — 기억 배선이 아니다. **모델이 다른 모양으로 불렀다**(카드 원장이 말한다)
```
① 카드 1  "… 메시지 입력 누르기"              ← click (바깥으로 아님 · 열쇠 없음)
① 카드 2  "… 메시지 입력 에 글자 넣기"         ← type  (바깥으로 아님 · 열쇠 없음)
① 카드 3  "… 그 칸 에 글자 넣기"               ← type  (바깥으로 아님 · 열쇠 없음)
① 카드 4  "… \"지파오가 …\" 보내기"            ← **바깥으로=true · 열쇠 생성·기억됨**
② 카드 1  "… 메시지 입력 에 글자 넣기"         ← **바깥으로=true 아님** → 미상 등급 → 카드
```
두 번째 턴의 걸음은 **전송으로 신고되지 않았다.** 그래서 헌장 ③ 조건(아는 상대)에 닿지 않고
미상으로 갔다 — 수리는 제 자리에서 돌았고(첫 발신의 "보내기" 카드는 열쇠를 만들었다),
**모델이 같은 일을 매번 다른 모양으로 부른다**는 사실이 남았다.

## 드러난 구조 사실 — 열쇠가 **모델의 자기 신고**에 달려 있다
`기대.바깥으로 === true` 를 모델이 밝혀야 전송으로 잡히고 기억도 붙는다. 밝히면 카드 한 번
뒤 조용해지고, 안 밝히면 영영 미상 카드다. 같은 일(같은 방·같은 문구)인데 **부르는 모양에
따라 마찰이 갈린다** — 사거리 비대칭병을 손 사이에서 없앴더니 **같은 손 안의 호출 모양 사이**에
남아 있었다.
