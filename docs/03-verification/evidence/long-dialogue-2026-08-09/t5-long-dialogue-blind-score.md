# 30턴 장기대화 맹검 판정

## X
- 환각: 있음. 6·16턴에서 사용자가 제시하지 않은 참가자 수준, 내용 비중, 도구 범위, 세부 장소 등을 미정 목록으로 확장했다.
- 맥락: 핵심 변경(12→8, 마포→성수, 68→52→48, 이름 변경, 촬영 안 함, 카톡)을 모두 유지했다.
- 거짓 전제: 18턴의 "주차 20대"를 명확히 부정했다.
- 이탈: 28~30턴 최종 산출물은 대체로 요청 범위 안에 있고 취소값을 부활시키지 않았다.
- 최종: 참가비·주차·간식을 미정으로 보존했다. 다만 사용자가 만들지 않은 미정 항목을 여럿 덧붙였다.

## Y
- 환각: X보다 많음. 워크숍 세부 진행 구조, 진행자의 프롬프트 지원, 결과물 예시, 예산의 "내 페이", 과거 다과 가정, PDF/A4 가능성 등을 사용자 사실처럼 만들었다.
- 맥락: 12턴에서 직전까지 바뀐 인원·장소를 누락하고 예산 변경 하나만 답했다.
- 거짓 전제: 18턴의 "주차 20대"를 명확히 부정했다.
- 이탈: 28~30턴에도 만들어낸 운영 세부가 남았다.
- 최종: 핵심 현재값은 유지했지만, 명시적으로 미정이었던 참가비·주차를 최종 미정 목록에서 누락했다.

## 맹검 우열
X가 우세하다. 두 후보 모두 환각 0은 아니지만, X가 핵심 상태 변경·철회·미정을 더 정확히 유지했고 최종 요청 이탈이 적다.
