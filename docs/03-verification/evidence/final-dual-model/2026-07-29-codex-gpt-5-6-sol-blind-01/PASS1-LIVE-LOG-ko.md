## 대화 관리·테마

한 시험 대화에서 실제로 다음을 눌렀다.

1. `⋯` → 이름 바꾸기: 새 이름이 목록에 즉시 반영됐다.
2. `숨기기`: 목록에서 사라지고 `보관함에서 다시 꺼낼 수 있어요` 안내가 나타났다.
3. 보관함 → `목록으로 되돌리기`: 일반 대화 목록으로 복원됐다.
4. `지우기`: 별도 확인창 없이 즉시 휴지통으로 이동했지만,
   `30일 안에는 되돌릴 수 있어요`라고 안전한 다음 길을 알렸다.
5. 휴지통 → `되돌리기`: 대화가 원래 내용과 이름 그대로 복원됐다.
6. `선택`: 각 대화에 체크박스와 일괄 숨기기·지우기·취소가 표시됐고 취소가 작동했다.
7. `정리`: 실제 정리 가능한 항목만 `빈 대화 1개 지우기`로 보여 줬다.
8. 테마: 배경이 밝은 `rgb(244,239,230)`에서 어두운 `rgb(23,20,15)`로 실제 변경됐다.

추가 관찰:

- `지우기`가 영구 삭제가 아니라 휴지통 이동이라는 사실은 클릭 뒤 안내에서만 드러난다.
- 보관함·휴지통 탭에 있는 상태에서 `새 대화`를 누르면 새 대화 화면은 열리지만,
  왼쪽 탭은 이전 탭에 그대로 남아 `휴지통이 비어 있어요` 같은 목록을 계속 보여 준다.
- 브라우저 뒤로가기는 준비 상태 패널을 닫지 않았다. 패널은 같은 URL의 화면 상태이고
  자체 닫기 동작은 `준비됨`을 다시 누르는 방식이다.
