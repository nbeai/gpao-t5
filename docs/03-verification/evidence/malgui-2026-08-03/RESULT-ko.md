## 3. 갈린 자리

**5번 — "이번 달에 내가 뭐 했는지 기억이 안 나."**
T5 는 지난 대화를 실제로 검색해 구체 사실을 냈다(정산 매출 1,305,000원 / 수수료 26,578원,
카페24 인증 없어 멈춘 지점, Developer 폴더 조사 요청 등). 그리고 마지막에 범위를 밝혔다 —
"이번 달 전체 기록이라기보다 현재 검색으로 잡힌 주요 작업만 추린 거예요."
**본 범위와 못 본 범위를 사실로 남기는 계약이 사용자 문장에 실제로 나타났다.**
OpenClaw 는 302초 만에 실패했다.

**4번 — "컴퓨터가 느려진 것 같아."**
둘 다 실제로 살펴봤다. T5 는 프로세스 부하를 수치로 냈고(`openclaw` 130.3% 등)
`ps` 가 막혀 거기까지만 봤다고 밝혔다. OpenClaw 는 CPU·메모리·디스크·업타임까지 더 넓게 봤고,
자기가 띄운 진단 프로세스 잔재를 치웠다고 밝혔다. **넓이는 OpenClaw, 속도는 T5(17.7s vs 149.5s).**

## 4. T5 결함 — 이번 측정에서 드러난 것

**말투가 문항마다 바뀐다.** 1·4·7번은 반말("잘 안 잡혀", "네가 확인해 주면", "말해줘"),
2·3·6·8번은 존댓말이다. 같은 사용자, 같은 세션 조건인데 어투가 흔들린다.
사람 말 항목에서 점수를 깎인 **유일한 이유**가 이것이다. OpenClaw 는 8문항 내내 존댓말이고
사용자를 "윤님"으로 부른다.

이건 취향 문제가 아니라 **동반의 일관성** 문제다. 사람은 말투가 흔들리는 상대를 같은 상대로
느끼지 않는다. 별도 항목으로 처분해야 한다.

## 5. 이 측정이 말하지 않는 것

- 도구 사용·완주·자동화 능력(첫 턴만 쟀다).
- Hermes·Codex 에 대한 어떤 것도.
- 채점자가 T5 를 만든 쪽이다. **인간 맹검을 대체하지 않는다.** 원문을 남긴 이유가 그것이다.
- 문항 8개는 표본이 작다. 결론이 아니라 **첫 근거**다.
