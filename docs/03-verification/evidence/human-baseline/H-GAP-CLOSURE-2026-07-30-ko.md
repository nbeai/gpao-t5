# H01~H10 기준선 — 감사 지적 4건 공백 측정

- 상태: `MEASURED` (판정은 감사·오너 몫)
- 실행: 개발팀(Claude). 오너 조작 0. 실제 서버·브라우저·`gpt-5.1`. 제품 코드 변경 0.
- 계측 보강: 완료를 **기다린 뒤** 값을 낸다(`__wait`). 그래서 이 문서에는 `null` 이 없다.
- 앞선 관측의 H01·H04·H08 공통 결함, H03·H09·H10 변동, 파일 손 범위 결함은 그대로 유효하다.

## 공백 1 — H02 는 자가학습을 증명하지 않았다 (지적 타당)

앞선 측정은 **H01 에서 명시 저장한 선호의 재사용 + 같은 대화 맥락**이었다. 시나리오 정의를
잘못 읽었다. 그래서 **명시 저장이 없는 깨끗한 상태**에서 다시 쟀다.

같은 정리 작업을 표현만 바꿔 세 번(기억 0에서 시작):

| 턴 | 원문 | 완료 | 최장공백 | 카드 | 다시 물었나 |
|---|---|---|---|---|---|
| 1 | `7월 매출 1200, 비용 800, 신규고객 14명, 이탈 3명. 이거 좀 정리해줘.` | 8.2s | 0 | 0 | 아니오 |
| 2 | `8월 것도. 1350 / 900 / 신규 11 / 이탈 5` | 7.2s | 0 | 0 | 아니오 |
| 3 | `9월도 부탁. 1500 / 950 / 신규 9 / 이탈 2` | 6.3s | 0 | 0 | 아니오 |

같은 대화 안에서는 축약 표현까지 이어받았다. **그런데 학습은 0이었다.**

- 3회 반복 뒤 `/memory`: **후보 0 · 반영 0.** 아무것도 남지 않았다.
- 새 대화에서 같은 축약 표현 `10월 것도. 1600 / 1000 / 신규 12 / 이탈 4` (완료 4.5s):
  `1600` 을 **총 세션 수**, `1000` 을 **재방문(기존)** 으로 읽었다. 매출·비용이 아니다.
  그리고 `이전에 쌓아둔 월별 수치를 내가 따로 갖고 있지는 않아서` 다시 적어 달라고 했다.

**판정 재료: 반복 경험의 자가학습 0.** 같은 대화 맥락 유지와 자가학습은 다른 사실이고,
현재 코어에는 후자가 없다. 이것이 새 T-cell 계획의 가장 직접적인 근거다.

## 공백 2 — H05 는 저장 지속과 의미 승계를 구분해야 했다 (지적 타당)

앞선 측정은 재시작 뒤 **파일이 남아 있는지**만 봤다. 그건 저장 지속이다. 의미 승계를 따로 쟀다.

| 조건 | 결과 | 완료 |
|---|---|---|
| 재시작 뒤 **같은 대화**에서 `아까 그 정리 이어서 10월도 같은 방식으로 해줘. 1600 / 1000 / 신규 12 / 이탈 4` | **성공** — 같은 숫자를 매출·비용으로 정확히 읽고 9월과 비교, 7~10월 전체를 합쳐 정리 | 11.6s |
| **새 대화**에서 `아까 그 최종본 이어서 정리해줘.` (3회차) | **실패** — 승계 0, `어떤 문서인지 한 줄만 알려주면` 되물음 | 13.6s |

즉 **의미 승계는 대화 경계에서만 끊긴다.** 재시작은 원인이 아니다.
H05 3회차까지 포함해 새 대화 승계는 **3/3 실패**, 재시작 뒤 같은 대화 승계는 **성공**이다.
앞선 문서가 이 둘을 한 칸에 뭉갠 것은 잘못이었다.

## 공백 3 — H10 은 에이전트 위임·회수·통합을 재지 않았다 (지적 타당)

원문: `Developer 폴더의 프로젝트들을 폴더별로 나눠서 조사하고, 각각 뭐 하는 건지 알아낸 다음
하나의 비교 보고서로 합쳐줘. 여러 갈래로 나눠서 해도 돼.`

| 항목 | 결과 |
|---|---|
| 에이전트 선택·언급 | **0** (`에이전트`·`병렬`·`나눠서 동시`·`위임` 전부 없음) |
| 갈래 나눔 | **0** — 위임을 명시적으로 허락했는데도 나누지 않았다 |
| 실제 조사 | 도구 2개, 폴더 3종만 언급 |
| 결과 통합 | **없음** — `내가 다음 턴에 바로 할 일은…` 으로 실행을 다음 턴으로 미뤘다 |
| 되물음 | 1회 (`제외하고 싶은 폴더 있으면 알려줄래?`) |
| 첫 표시 · 완료 | 18.5s · 18.5s |

**판정 재료: 에이전트 운용 0.** 인수인계 §1 의 `Claude Code, Codex와 다른 에이전트를 상황에 맞게
운용하고 결과를 현재 맥락과 Truth Ledger로 합친다` 는 현재 코어에 없다.

(b) 카드 대기 턴은 어시스턴트 텍스트가 늘지 않아 완료 판정이 서지 않았다.

카드 수·클릭 수로만 기록한다.
