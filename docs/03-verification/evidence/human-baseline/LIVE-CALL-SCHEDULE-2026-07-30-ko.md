## 3. API 호출 수·토큰 — 추정하지 않고 실측으로 채운다

프롬프트 1건이 유발하는 API 호출 수는 제품 에이전트 루프에 달려 있어 사전 확정이 불가능하다.
빈 칸을 숫자로 채우지 않는다. 대신:

- OpenClaw: `agent --json`이 주는 `apiCalls`·`tokens`·`costUsd`를 턴마다 기록한다. 없으면 `null`.
- Hermes: TUI가 표시하는 토큰 수치가 transcript에 남으면 옮기고, 없으면 `null`.
- 관측 앵커(참고용, 판정 근거 아님): Hermes oneshot(`-z`) 1턴 입력 5,746토큰.
  TUI 세션은 맥락 누적으로 턴이 갈수록 이보다 커진다.

## 4. 비용 — 단가 미확정

- Hermes는 `gpt-5.1`, OpenClaw는 카탈로그 제약으로 `gpt-5.3-chat-latest`로 돈다.
- 두 모델의 확정 단가표를 현재 저장소가 갖고 있지 않다. **금액 추정을 만들지 않는다.**
- OpenClaw `costUsd`가 기록되면 그 값을 보고하고, Hermes는 토큰 실측 뒤 오너가 공급자
  콘솔 단가로 환산할 수 있게 토큰 수를 남긴다.

## 5. 폭주 억제 장치 (이미 계측기에 있음)

- 턴 타임아웃 240s — 초과 시 프로세스 그룹 종료, Hermes는 해당 분기 중단(다른 분기 유효 유지)
- 홈별 단일 writer(`SessionHost` 구조 강제) · 회차 lock · 턴 전후 프로세스 수 검사
- 유료 실행 전제: 자격 파일이 없으면 시작하지 않음(exit 2)

## 6. 회차 1 게이트

회차 1이 끝나면 `verify_run.py` 구조 판정 VALID와 usage 집계(호출 수·토큰·비용)를 보고하고,
그 실측으로 회차 2·3 계속 여부를 판정한다. 실측 없이 3회차 연속 실행을 예약하지 않는다.
