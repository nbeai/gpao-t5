## 1. 판정 요약

이전 감사의 핵심 보강은 실제로 들어왔다. `preflight.py`는 유령·가짜 세션 재개를 거절하고,
가짜 키로 영속된 세션의 재개를 디스크 사실과 이전 원문 재생으로 확인한다. 실패·시간초과 분기,
프로세스 계측 불능, 기존 회차 덮어쓰기, 상수 `modelCalls: 0` 문제도 보강됐다.

그러나 자격 입력 뒤 얻을 결과가 T5 기준선과 비교 가능하다는 보장은 아직 성립하지 않는다.
또한 실제 `~/Downloads` 파일을 정리하는 경계에 사용자 파일 삭제 가능성이 남아 있다.
따라서 오너 자격 요청과 유료 회차 1은 계속 차단한다.

## 3. 문제

### P0-1. H02·H10이 봉인 기준선과 다른 시험이다

`h-branches.json:17-21`의 H02는 폴더 내용 확인을 세 번 바꿔 말하는 시나리오다.
봉인된 T5 H02는 `H-GAP-CLOSURE-2026-07-30-ko.md:17`부터의
월별 매출·비용·신규·이탈 숫자 정리와 새 대화 축약 해석이다.

이 차이는 문구 차이가 아니라 능력 차이다. 현재 분기표는 T5에서 확인된
“같은 대화 맥락은 유지하지만 반복 경험을 저장하지 않아 새 대화에서 숫자 의미를 잃는다”를
같은 조건으로 재지 않는다.

`h-branches.json:74-76`의 H10도 Downloads·Documents 견적서 비교다.
봉인된 T5 H10은 `Developer` 프로젝트들을 나눠 조사하고, “여러 갈래로 나눠서 해도 돼”라는
명시적 위임 허용 아래 에이전트 선택·위임·회수·통합을 재는 시나리오다.
현재 분기표는 그 위임 조건과 대상을 제거했다.

따라서 이 실행표로 얻는 H02·H10 결과는 봉인된 T5 기준선과 직접 비교할 수 없다.
H02와 H10은 앞선 인간 기준선에서도 한 차례 잘못 측정됐다가 감사로 정정된 항목이다.

### P0-2. 실행 중 교체된 사용자 파일을 fixture로 오인해 삭제할 수 있다

두 계측기는 시작 전에 동명 파일 충돌을 확인하고 배타 생성한다. 이 부분은 개선됐다.
그러나 소유권 기록은 생성한 파일의 신분이 아니라 경로 문자열뿐이다.

- Hermes: `h_runner_v3.py:308-315`
- OpenClaw: `h-runner.mjs:367-373`

긴 회차 중 계측기가 만든 파일이 없어지고 사용자가 같은 경로에 새 파일을 만들면, 종료 정리는
그 새 파일을 스냅샷한 뒤 삭제한다. `fixture_unlock()`도 같은 경로에 현재 존재하는 파일의 권한을
바꾼다. 시작 시 충돌 검사는 실행 중 신분 교체를 막지 못한다.

이는 이전 감사의 “정확한 경로는 소유권이 아니다”라는 P0와 같은 유형이다. 실제 사용자
`~/Downloads`를 대상으로 하므로 유료 실행 전 차단 사항이다.

### P1-1. Hermes 턴 완료가 실제 완료가 아니라 4초 무출력이다

`h_runner_v3.py:102-126`은 첫 출력 뒤 4초 동안 새 PTY 바이트가 없으면 턴이 끝났다고 간주한다.
제품의 ready 상태나 응답 완료 신호를 확인하지 않는다. 모델·도구가 4초 넘게 조용하면 이전 작업이
계속 중인데 다음 프롬프트를 보낼 수 있어 턴 경계와 응답 귀속이 오염된다.

이는 이번 대응이 선언한 “증거 칸은 다르게 나올 수 있는 관측만 담는다”와 어긋난다.
출력 정지는 완료 사실이 아니다.

### P1-2. 정본 작업 폴더에서 OpenClaw 실행 대상이 없다

`h-runner.mjs:62-68`은 기본 실행 위치를
`scripts/compare-live/oc-2026.7.2`로 잡고, 선택적으로 `node-bin.txt`를 읽는다.
현재 정본 작업 폴더에는 둘 다 없다. `LIVE_DIR` 대체 경로는 코드에만 있고 정본 실행 스케줄과
인수인계에 실제 값·산출 위치·동기화 근거가 없다.

따라서 저장소 문서의 기본 명령은 dry-run을 넘겨 실제 OpenClaw 프로세스를 시작할 수 없다.
현재 상태는 “자격만 넣으면 회차 1 실행”이 아니다.

### P1-3. 필독 준비 문서가 여전히 폐기된 14턴 실행표를 현재 사실로 말한다

`T5-TCELL-PRESTART-BRIEFING-2026-07-30-ko.md`와
