# 비교군 라이브 계측기 Codex 인수 구현 증거

- 날짜: 2026-07-30 (Asia/Seoul)
- 범위: OpenClaw·Hermes H01~H10 라이브 비교 계측기와 준비 문서
- 제품 코드 변경: **0건**
- 판정: **CODEX_SELF_VERIFIED / CLAUDE_INDEPENDENT_AUDIT_PENDING**
- 유료 호출·실제 오너 자격 사용: **0건**

## 1. 인수 이유

이전 구현은 이미 배운 유형을 반복했다. H02·H10 원문이 봉인 기준선과 달랐고, fixture 경로를
소유권으로 오인했으며, Hermes 무출력 4초를 완료 신호로 썼고, 존재하지 않는 OpenClaw 실행 경로와
폐기된 14턴 문서가 남았다. 이는 각각 `정본 재입력`, `경로≠소유권`, `대용물≠제품 사실`,
`실행 활주로 미확인`, `투영 문서 미동기화`의 예방 가능 재발이다.

## 2. 구현

1. `h-scenarios.json`을 사용자 원문 단일 정본으로 만들고, `h-branches.json`은 `promptRef`만
   소비한다. `compare_contract.py`가 8분기·18턴·연속 번호·핵심 봉인 원문·활성 문서 잔재를 검사한다.
2. fixture는 생성 시 hard-link anchor, device, inode, SHA-256을 기록한다. chmod와 정리는 이
   신분이 모두 일치할 때만 허용한다. 정리는 경로를 먼저 원자 격리하고 신분을 재확인한 뒤 수행한다.
   실행 중 같은 경로가 사용자 파일로 교체되면 삭제하지 않고 보존하며 회차 검증을 실패시킨다.
3. Hermes 완료는 무출력 시간만으로 판정하지 않는다. 제품의 작업 상태 표식 뒤 입력 프롬프트가
   다시 나타난 사실을 관측하고, 그 뒤 화면 안정 시간을 확인한다.
4. OpenClaw 라이브는 불안정한 스크래치 빌드를 기본 경로로 가장하지 않는다. 실제 설치 실행 파일을
   찾고 `--version`과 `agent --help`의 필수 옵션을 확인하며, 실행 경로·버전을 영수증에 기록한다.
   현재 무과금 확인 신분은 `OpenClaw 2026.6.11 (e085fa1)`이다. pinned `2026.7.2`는 코드 비교
   자료로만 남긴다.
5. 기존 회차 폴더는 덮어쓰지 않는다. Python 계측기도 기존 회차를 발견해 조기 종료할 때 그 폴더의
   영수증을 수정하지 않도록 수명주기를 분리했다.
6. 필독 준비 문서와 인간 기준선 문서를 18턴·현재 런타임·소유권·완료 신호 계약으로 동기화하고,
   옛 14턴 준비 문서는 `RETIRED / 실행 금지`로 내렸다.

## 3. 반대 검증

- 정본 원문을 실행표에 직접 다시 쓰거나 모르는 `promptRef`를 쓰면 시작 실패
- fixture 경로를 삭제하고 다른 내용의 파일을 만들면 chmod 거부·삭제 0·교체 파일 보존
- 존재하지 않거나 디스크에 없는 Hermes session ID는 재개 실패
- 가짜 키로 실제 저장된 session ID만 이전 원문과 함께 재개 성공
- Hermes 작업→입력 프롬프트 복귀가 없으면 완료로 인정하지 않음
- OpenClaw 실행 파일 또는 필수 `agent` 옵션이 없으면 dry-run 전 시작 실패
- 활성 문서에 폐기된 `회차당 14턴` 또는 `h-turns.json`이 남으면 계약 감사 실패
