## 3. 라이브가 잡은 결함과 수정 (전부 라이브 재측정으로 확인)

1. **`evidence`가 선택 항목이었다.** 계약이 요구하는 근거를 스키마에서 선택으로 둬서 모델이
   생략할 수 있었다 → `required: ['statement', 'evidence']`로 고정.
2. **모델이 인용은 정확한데 statement를 요약했다.** 게이트는 설계대로 확인 통로로 강등했지만
   사용자에게는 카드가 남았다. 게이트 계약(`statement === quote`)은 그대로 두고, 그 **기계
   규칙을 도구 설명에 정확히 알렸다**(금지문이 아니라 현실 공급 — 2축). 재측정 3/3 반영.
3. **승인 턴에서 기억 사실이 화면에 안 나왔다.** 철회는 됐는데 표면이 침묵해 사용자에게는
   "안 지워졌다"와 구분되지 않았다 → 승인 경로에서도 기억 카드를 렌더한다.

이 셋은 모두 코드에서는 통과하던 것이 **실제 모델·실제 화면에서만 드러났다.**

## 4. 남은 결함 (감사 회부 — 경계 판정 요청)

H04 턴에 **파일 되돌리기 승인 카드가 함께 뜬다**(3회 모두 `local.file`).
기억은 정상 철회되고 이제 "그 기억은 지웠어요"도 표시되지만, 사용자는 자기가 요청하지 않은
승인 카드를 하나 더 본다.

- 원인: 기억이 아니라 도구 추론 — `src/kernel/l1-intent/intent.js:71`의 `취소해` → `local.file`,
  `src/kernel/l1-intent/file-parse.js:14`의 `undo` 패턴.
- 조치: **손대지 않았다.** 계획 §5가 이 슬라이스에 금지한 구역(도구 선택 정책)이다.
- 판정 요청: 이 자리를 여는 경계 예외를 허용할지, 아니면 후속 파일 손 슬라이스로 넘길지.
