# S1 결과 — 커널이 사용자 입으로 말하는 것을 멈췄다

2026-08-05 · 라이브 실모델 `gpt-5.1` · 격리 증명 PASS · 계측 `GPAO_T5_PROMPT_DUMP`

## 1. 닫는 문장 — 라이브

같은 발화, 같은 모델. 왼쪽은 오너가 실제로 받은 답이다.

**전**
```
안녕, 나는 GPAO-T5야.
말해 준 환경이랑 할 수 있는 일들 다 이해했어.
웹에서 찾기, 로컬 파일·폴더 다루기, 터미널 명령, 브라우저로 화면 보기까지는 내가 직접
처리할 수 있고, 메일·텔레그램·슬랙 같은 건 지금은 직접 연결은 안 된 상태네.
이제 뭐부터 같이 할까?
```

**후**
```
안녕, 나는 GPAO-T5야.
뭐부터 같이 해볼까?
```

능력 목록 **0** · 미연결 서비스 목록 **0** · "말해 준 환경이랑 … 다 이해했어" **0**.

## 1-1. 동시 보호 — 물어보면 여전히 정확하다

`"너 지금 실제로 뭘 할 수 있어?"` → 웹·브라우징 / 로컬 파일 / 터미널·시스템 / 위치 찾기 /
캡슐 자동화 / 지난 대화 검색 / 외부 연결 준비를 정확히 답했다.
**오히려 더 정확해졌다** — 파일 범위를 "작업 영역(fixture) 안에서"라고 말했고 그게 실제 격리 방이다.
프롬프트가 능력을 안 읊어도 **도구 스키마만으로 자기 손을 안다**(원리 ③).

| | S1 전 | S1 후 |
|---|---|---|
| **사용자 메시지(커널 목소리)** | **1,574자** | **2자** (`안녕`) |
| system 전체 | 3,746자 | 5,482자 |
| 그중 안정(캐시에 얹힘) | 3,717자 | 5,218자 (**95%**) |
| 도구 스키마 | 17,285자 | 17,285자 |

**불변식 B 판정** — 사용자 턴은 캐시에 안 얹힌다. 1,574자를 매 콜 새로 지불하던 것이 2자가 됐고,
옮겨간 자리는 **95%가 안정 구역**이라 두 번째 턴부터 캐시에 얹힌다.

**곁가지로 드러난 수치** — 도구 스키마가 **17,285자**로 시스템 프롬프트의 3.2배다.
불변식 B 가 겨눈 자리는 여기다. S7·S8 에서 다룬다.

## 3. 무엇이 문제였나

`buildModelMessages` 는 `usr` 배열에 커널이 쓴 블록을 최대 열넷 쌓고 **맨 마지막에 사용자 발화**를
붙인 뒤, 전부 하나의 문자열로 이어 붙여 보냈다. 모델 입장에서는 **전부 사용자가 한 말**이다.

```
[다른 대화에서 이어받을 수 있는 작업]  [저장된 기본값]  [직전 답이 놓고 쓴 것]
[이번 턴 실행 사실]  [바깥 자료에 닿는 현실]  [이번 턴의 연결 입력·확인 사실]
[T5가 먼저 맡을 수 있는 일]  [막힌 것과 다음 길]  …            ← 그리고 사용자 발화
```

같은 프롬프트의 시스템 구역에는 **"묻지 않은 능력 나열 금지"** 가 적혀 있었다. 말과 행동이 반대였다.

**S0 에서 못 찾았던 반쪽도 여기서 나왔다.** `"메일·텔레그램·슬랙 같은 건 안 된 상태네"` 는
`[바깥 자료에 닿는 현실]` 의 **미연결 서비스 목록**이었다(`직접 연결 없음(연결하면 가능)`).
모델이 지어낸 게 아니라 **우리가 사용자 입으로 말했다.**

그 블록에는 이미 흉터가 있었다 — *"실측(2026-08-03): 순수 대화 세 턴에서 이 블록 1,524자가
바이트까지 같게 세 번 놓였다. 매 턴 처음인 것처럼 놓으면 모델은 매 턴 처음인 것처럼 읊는다."*
그때의 처방은 **"이미 놓였다"는 한 줄을 앞에 얹는 것**이었다. 증상에 붙인 말이지 자리를 옮기지 않았다.

## 4. 무엇을 했나 — 지우지 않고 옮겼다

사실을 지우면 실측으로 얻은 것을 잃는다(없으면 모델이 "사용자에게 무엇을 시킬까"를 먼저 생각한다).
**틀린 것은 사실이 아니라 자리였다.**

- `[네가 먼저 맡을 수 있는 일]` · `[바깥 자료에 닿는 현실]` → **시스템 안정 구역**
  (바깥 현실은 **맨 끝**에 둔다 — 서비스가 붙어 바뀌어도 그 뒤쪽만 무효화된다. 불변식 A 예외 ② 와 같은 원리)
- 나머지 커널 블록 전부 → **시스템 휘발 구역**
- 사용자 메시지 → **사용자가 말한 것만**

도구 결과를 정규 도구 메시지로 돌리는 일은 **S2** 가 한다. 여기서는 목소리만 바로잡았다.

## 5. 검사가 통과하면서 깨져 있던 자리

처음 쓴 S1 검사는 `demoContext` 로 쟀는데 **거기엔 외부 서비스가 없다.** 그래서
`[바깥 자료에 닿는 현실]` 이 아예 안 만들어졌고 검사는 초록이었다.
라이브 덤프를 열어 보고서야 사용자 메시지에 그 블록이 1,500자쯤 그대로 있는 것을 봤다.

→ 검사 ⑥ 을 **외부 서비스가 있는 설치**로 다시 세웠고, ⑦ 로 "바뀌어도 안정 접두 70% 이상이 살아 있는가"를 잰다.
**재는 자리를 라이브와 같게 만들지 않으면 초록은 거짓이다.** 오늘 두 번째다.
