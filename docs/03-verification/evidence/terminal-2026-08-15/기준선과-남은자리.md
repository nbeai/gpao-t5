## 0. 가장 중요한 사실 하나 — **모델 문제가 아니다**

같은 질문을 두 곳에 넣었다(오너 실측 2026-08-15).

```
질문   "작업 폴더에서 제일 긴 문서가 뭐야?"

클로드코드 + 소넷 4.6 (최저 사양)

**더 약한 모델이 더 좋은 답을 냈다. 차이는 터미널을 썼느냐 하나다.**

→ **부품 문제가 아니라 배선 문제다.** 이 한 줄이 오늘의 결론이다.

## 1. 시험 방법 — **지어내지 마라**

`scripts/terminal-qualification/그냥써본다.mjs`

```bash
node scripts/terminal-qualification/그냥써본다.mjs "작업 폴더에 뭐가 들어있는지 좀 봐줘" "그 중에 제일 긴 문서가 뭐야?"

가짜 집·채점 축·「옳은행동」 정의·멀티턴 대본 **전부 없다.**
격리 방에 **이 저장소의 진짜 문서**를 넣고, **오너가 클로드코드에게 하는 말을 그대로** 친다. 판정은 사람이 답을 읽고 한다.

> **오너 지시(2026-08-15)**: *"티파이브의 테스트는 오픈클로나 헤르메스나 클로드코드가 할 줄 아는 걸 하느냐와 똑같은 거야. 그냥 똑같은 시스템 만드는 거야. 거기에 티파이브의 특성을 입히는 거고."*
> *"내가 비개발자라고. 너에게 이것저것 요구하고 있고 너는 그걸 수행하고 있잖아. **이게 기본이다.**"*

**지어낸 과업 다섯(`tasks.mjs`)은 개발자 시험이었다** — node 버전·CPU 아키텍처·csv 필터링. 비개발자 제품에 개발자 시험지를 만든 것이고, 그게 하루를 잡아먹었다. 같은 실수를 반복하지 마라.

⚠️ **이 자로 쓸 수 있는 숫자는 터미널 호출 수 하나다** (손 관리자 정정 2026-08-15).

나머지는 최상위만 보고 답했다. **오너가 지적한 그 얕음을 맨몸 팔도 저질렀다.**
「터미널을 잡는다」는 배선이고 「끝까지 재고 답한다」는 손이다 — 후자는 별도 라이브가 잰다.

그리고 F-116(터미널 선언 수리)이 걸린 작업트리에서 `그냥써본다.mjs` 실측:
**터미널 0회 · local.file 6회** — 팔 D 예측과 일치. **F-116 단독으로는 안 산다.**

**결론**: 죽이는 겹은 「**파일 손 선언이 자기를 과대 선언하고 한계를 말하지 않는 것**」이다.

- `demo-context.js:774` capability — "한 번에 한 자리" 뒤에 집계(여러 파일 세기·훑기)의 한계가 없다
- `demo-context.js:790` schema — "읽기는 이 컴퓨터의 홈 전체" 과대 선언
수리는 E 팔에서 검증된 그대로 **빠진 사실 채우기**(유도): *"여러 파일을 한꺼번에 세거나
줄 수를 재거나 훑는 일은 이 손으로 하나씩 하면 오래 걸린다 — 그런 일은 터미널이 명령
하나로 끝낸다."* 증거 원본: `맨몸대조군-*.json` (이 폴더).

## 7-ao. ★ 오너 결정 — **어법 외우기 금지** · 밟아서 안다 (2026-08-16)

**상태(2026-08-16): 선반.** §7-aq 검문에서 「절반 이행 갈라짐」이 나와 오너 결정 대기로
멈췄고, 오너는 (가)+(나)(§7-ar)로 먼저 트는 것을 승인했다. 아래 선등록·검문 기록은 재개
시점의 정본이므로 접지 않는다.

> 오너: *"외우기 금지하자."*

§7-an-5 로 올린 결정이 내려왔다. 「이 실패가 우리 샌드박스 때문인가」를 **stderr 어법으로
알아맞히는 것을 그만둔다.** 이건 새 발상이 아니라 `sandbox.js` 첫 문단으로 **돌아가는 것**이다:
*"명령이 위험한지 알아맞히지 않는다. 돌려 보고 안다. 목록은 항상 뚫린다."*

### 7-ao-1. 타당성 스파이크 — **갈라낸다** (진단 · 제품 코드 0줄)
사본을 만들고 거기서 쓰기를 열어 한 번 더 돌린 실행값:
```
사례                              probe exit   사본에서 exit   판정            사용자자리
tar -czf b-$(date +%s).tgz .          1           **0**      우리가 막았다      불변
sqlite3 "$(echo m.db)" "create …"     1           **0**      우리가 막았다      불변  ★ 어법이 못 잡던 미탐
awk -f /nonexistent/x.awk a.md        2            2         진짜 오류         불변
tar --그런옵션없음 -czf x.tgz .         1            1         진짜 오류         불변
grep -q zzz a.md                      1            1         안 막았다         불변
```
**5/5 정확**하고, 그 안에 §7-al-2 가 「못 고쳤다」고 신고한 `sqlite3` 미탐이 들어 있다.
어법 목록이 세 번 자라고도 못 잡던 것을 **한 규칙이 잡는다.**

### 7-ao-2. 왜 이것이 「규칙 하나」인가
```
지금    말투마다 갈래가 있다 — Permission denied · Failed to open · 대조 불능 …  (계속 자란다)
바꾸면  갈래가 없다. 물음이 하나다 — **「쓰기를 열어 주면 되는가」**
        되면 우리가 막은 것이고, 안 되면 진짜 오류다. 도구·판·로케일과 무관하다
```

### 7-ao-3. 선등록 (결과 보기 전에 고정)
```
닫는 문장(영역)  "막힌 이유를 문구로 알아맞히지 않는다 — 밟아서 안다"
                ✗ "sqlite3 말투도 알아본다"(집게)
설계            `재보기` 의 세 번째 계단. 지금 구조 그대로 늘린다 —
                probe(쓰기✗ 網✗) → [網만 열기 reach] → **[사본에서 쓰기만 열기]**
                · 사본: cwd 를 버릴 자리에 복사. **사용자 자리는 안 건드린다**(probeChangedNothing 유지)
                · 새 모드는 **網을 열지 않는다** — probe 가 바깥 효과를 내면 안 된다.
                  (스파이크는 `granted` 로 돌려 網이 열려 있었다. 그대로 쓰면 안 된다 · 신고)
                · 비밀·시그널·AppleEvent 는 probe 와 똑같이 닫는다
상한            복사 비용이 있다. **상한을 넘으면 안 밟고 「모른다」로 간다**(= 지금의 카드).
                상한값은 선등록에 숫자로 못 박은 뒤 잰다 — 결과를 보고 정하지 않는다
어법 처리       새 계단이 답을 내면 **어법 갈래는 안 본다.** 못 밟은 경우에만 지금 갈래로 내려간다.
                → 목록을 지우지는 않되 **자라지 않게 못 박는다**(전면 삭제는 회귀가 크다 · 별건)
반대시험 넷      ① grep 미검출 → 여전히 실패 아님   ② awk 없는파일 → 승인 카드 아님
                ③ 잘못된 옵션 → 진짜 오류         ④ **사용자 자리 불변**(사본에서만 돈다)
종료 조건       ㉮ `sqlite3` 미탐이 잡힌다(어법으로는 못 잡던 것)
                ㉯ 같은 방 라이브 전후 대조에서 **파일 생성과 개입 횟수를 함께** 잰다
                ㉰ 회귀 초록 · 게이트 기존 1건 외 증가 없음
못 낸다         **개입을 줄인다는 약속은 안 한다.** 이 수리는 「승인하면 되는 일」을 정확히
                가려낼 뿐이고, 되돌릴 수 있는 쓰기를 개입 0 으로 통과시키는 것은 **다른 칸**이다
알려진 한계     cwd 밖 절대경로에 쓰는 명령은 사본에 그 자리가 없어 「진짜 오류」로 보일 수 있다.
                그 갈래는 지금 말투 A 가 이미 잡는다 — **그래서 어법 갈래를 지우지 않는다**
```

## 7-ap. 착수 검문 — **조정. 안전 결함 하나를 잡았고 대안을 쟀다** (2026-08-16)

### 7-ap-1. 감시자가 잡은 것 — ㉠ **사본이 비밀 보호를 우회한다** (이론이 아니다)
```
왜   복사를 하는 주체는 샌드박스 안의 명령이 아니라 **샌드박스 밖의 T5 런타임(node)** 이다.
     `denySecretReads` 는 자식 프로세스에만 걸린다. 그리고 **기본 cwd 는 사용자 홈**이다
         (local-terminal.js `cwdOf() = homedir()`)
무엇  `secretProtection()` 세 축 중 사본 경로에서 살아남는 것은 **이름 규칙 하나뿐**이다:
        namePatterns  → 사본에도 걸린다 ✓
        SECRET_DIRS subpath → **안 걸린다** ✗
        ~/Library 닫힘(require-not) → **안 걸린다** ✗
     즉 홈을 복사하면 `~/Library/Messages/chat.db`·쿠키·브라우저 프로필·`~/.ssh/config` 가
     **쓰기가 열린 자리에 평문으로** 놓인다. 2026-08-02 P0-a 와 같은 가족이다
     (그 영역은 **승인으로도 안 열리는** 자리다). 복사 행위 자체가 유출이고,
     타임아웃·크래시로 정리에 실패하면 남는다
```
그 밖에 감시자가 못 박은 것: ㉡ **사본 결과의 상류 전달 규칙이 없다** — `재보기` 는 지금
`looksBlocked(둘째판) ? 첫판 : 둘째판` 인데 세 번째 계단은 **규칙이 정반대**여야 한다
(사본에서 통과 = 우리가 막았다 = 결과를 **버리고** 첫판으로 카드). 안 못 박으면 사본에서 만든
파일 목록·stdout 이 모델 입력에 실려 **"만들었습니다"** 라고 답한다 — 사용자 자리엔 없다.
㉢ 왕복이 셋으로 는다 · ㉣ 소유 파일 3개(`sandbox.js`·`local-terminal.js`·`terminal-run.js`) 미신고
· 선등록이 **미커밋**이라 「결과 보기 전 고정」이 기계로 보장 안 됨 · 어법 갈래 동결은 이번에서 빼라.

### 7-ap-2. 두 축을 쟀다 — **축 B(복사 안 함)는 성립하지 않는다**
감시자 제안: 복사하지 말고 **빈 자리를 cwd 로 주고 쓰기만 열자**(비밀·상한·성능이 한 번에 사라진다).
스파이크 cwd: 파일 1개·5B 임시방 — **라이브 기본 cwd(홈)와 조건이 다르다**(신고).
```
사례                            probe  축A(사본)  축B(빈자리)   판정
tar -czf b-$(date +%s).tgz .      1       0          0        같다 (우리가 막았다)
sqlite3 "$(echo m.db)" create     1       0          0        같다 (우리가 막았다)
awk -f /nonexistent/x.awk         2       2          2        같다 (진짜 오류)
tar --그런옵션없음                  1       1          1        같다 (진짜 오류)
grep -q zzz a.md                  1       1          2        같다 (진짜 오류)
───────────────────────────────────────────────────────────────────────────
mkdir 시작문서 (이미 있어 실패)      1       1          0        **갈린다** B 오탐 → 헛클릭
ln -s x a.md   (이미 있어 실패)     1       1          0        **갈린다** B 오탐 → 헛클릭
tar -czf out.tgz 시작문서           1       0          1        **갈린다** B 미탐
cp a.md a-사본.md                  1       0          1        **갈린다** B 미탐
```
```
읽는 법  축 B 는 앞 다섯만 보면 같은 답을 내지만, **cwd 의 내용에 의존하는 명령에서 갈린다.**
        오탐 둘은 「이미 있어서 실패」를 「우리가 막았다」로 승격해 **헛클릭**을 만든다.
        미탐 둘은 오늘과 같은 상태로 폴백이라 회귀는 아니지만 —
        ★ `cp a.md a-사본.md` 는 **§7-af ④(백업 폴더에 복사)** 그 발화의 명령 모양이다.
        제일 흔한 자리를 못 잡는 축은 쓸 수 없다
결론    **축 A(사본)로 간다. 단 ㉠ 을 닫고서만** — 복사 단계에 `secretProtection()` **전 축**
        (subpath·이름 규칙·닫힘 세트)을 적용하고, 심볼릭 링크 비추적 · **하드링크 금지**
        (`cp -al` 로 빠르게 뜨면 사본 쓰기가 원본 inode 를 바꿔 반대시험 ④ 가 조용히 무너진다)
```

### 7-ap-3. 아직 안 정한 것 — **이걸 정하고 선등록을 커밋한 뒤에 코드로 간다**

      ⚠️ 기본 cwd 가 홈이라 안전한 상한을 걸면 **기본 경로에서 거의 항상 초과 → 「모른다」**.

㉡     사본 결과의 상류 전달 규칙과 `probeChangedNothing` 취급을 문장으로 확정

## 7-aq. 손 관리자 검문 — **선등록대로 배선하면 오늘 되던 것 둘이 죽는다** (기계 실측 2026-08-16)

판정: **한 칸 나아갔다 — 단 선등록 두 줄을 고치기 전에는 착수 안 한다.**
손 관리자가 선등록 §7-ao-3 문장 그대로 세 번째 계단을 재현하고, **`granted`(승인 후 실제 결과)를
정답지로 나란히** 붙여 쟀다.

### 7-aq-1. 밟은 값 — 양성은 6/6, **음성이 2/4 틀렸다**
```
명령                                오늘 판정          사본계단      granted(정답지)   차이
tar -czf b-$(date +%s).tgz .        sandbox/unproven   0 → 카드      0 성공           일치
sqlite3 "$(echo m.db)" "create …"   code/failed(미탐)  0 → 카드      0 성공           ★ 잡았다
awk -f /nonexistent/x.awk a.md      code/failed        2 → 무카드    2 실패           일치
grep -q zzz a.md                    code/failed        1 → 무카드    1 실패           일치
cd .. && tar -czf backup.tgz home   sandbox/write(카드) 1 → 무카드   **0 성공**       ★ 죽는다
tar -czf /절대경로/x.tgz 작업         sandbox/write(카드) 1 → 무카드   **0 성공**       ★ 죽는다
```
**내 스파이크 5/5 는 「사본 안에서만 쓰는 명령」만 골라 잰 값이었다.** 자리를 하나 넓히자 뒤집혔다.
원인: 복사 단위는 `cwd` 인데 **명령이 실제로 도는 자리는 다르다**(`cd ..`·절대경로).
라이브 카드 7개 중 **4개가 명령 문자열 안에서 자리를 바꾼다**(`cd ~`·`cd /`·`cd <절대경로>`·`find ..`).

### 7-aq-2. 그래서 고칠 선등록 두 줄 (손 관리자 처방 · 이 값으로 죽는 둘이 되살아나고 sqlite3 는 그대로 잡힌다)
```
① 우선순위    사본의 **exit 0 만** 말한다(= 우리가 막았다).
             **exit≠0 은 「모른다」**이고 어법 갈래로 내려간다.
             ← 음성을 증거로 쓰지 않는다. F-105 · §7-al-4 (ㄱ) 이 말한 그 문장이다
② 발동 범위   **오늘 `code/failed` 로 떨어지는 갈래에서만** 밟는다.
             오늘 이미 `sandbox/*` 인 것은 안 건드린다
```
### 7-aq-3. ★ 그러면 오너 문장을 **절반만** 이행하는 것이다 — 그렇게 적는다
```
오너 지시   "외우기 금지하자"
할 수 있는 것 **어법 밑에 진짜 자를 하나 깐다** — 어법이 못 잡던 것을 밟아서 잡는다
할 수 없는 것 **어법을 지우는 것.** 지우려면 사본이 cwd 밖까지 충실해야 하는데
