# P-OP-3 공통 탐색 손 라이브 재검증

시각: 2026-07-28

## 결과

`카페24 주문 가져와줘.`를 실제 모델에 한 번 보냈다.

**미통과.** 모델은 공개 API 문서를 읽고 비밀을 채팅에 붙이지 말라고 했지만, 현재 존재하지 않는 연결/비밀 입력 화면을 조건부로 언급하며 `mall_id`와 access token을 요구했다. 원장에는 미확인 실행도 남았다.

## 해석

`local.discovery` 등록과 헌장 보강만으로는 충분하지 않다. 탐색 결과가 "현재 전용 연결 경로 없음"이라는 실행 사실로 다음 계획·답변에 전달되지 않는다. 다음 수정은 서비스별 문구가 아니라, discovery receipt의 후보/부재/확인 범위를 연결 가능성 판단과 복구 경로에 사실로 전달하는 계약이어야 한다.

## 금지

- 카페24 API 항목을 하드코딩하지 않는다.
- 대화로 비밀값·식별자를 받는 길을 만들지 않는다.
- 존재하지 않는 비밀 입력 표면을 약속하지 않는다.
