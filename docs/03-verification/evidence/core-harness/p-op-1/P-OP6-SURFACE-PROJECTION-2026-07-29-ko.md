# P-OP-6 · 사용자 표면 투영 계약 (2026-07-29)

원칙(오너 감사 지정): **내부 실행에는 원시 식별자를, 사용자 표면과 기억 후보에는 검증된
사람말 라벨을 쓴다. 하나의 표면에는 하나의 확정된 대상 사실만 투영한다.**
항목별 문구 패치가 아니라 표시 경로마다 **단일 변환 경계**를 확정한다.

## ② 이번에 닫은 것

1. **Codex `e2ac91d` 흡수**(cherry-pick `c21dfad`, 의미 단위 검토 후 전량 필요 판정):

   승인 카드 scope/where 상충 제거(`확정된전송미리보기` — 계획·걸음 경로 공통) ·
   sentVia 라벨 승계 · 빈 답 말풍선 생략. 검사 포함(카드에 scope 부재 · 라벨만 노출).

채널 답장의 전달 원장 기록 · 승인 알림의 도구 id 비노출·같은 말투 · allowlist 게이트의

과거 채널 왕복 전달 20건.
