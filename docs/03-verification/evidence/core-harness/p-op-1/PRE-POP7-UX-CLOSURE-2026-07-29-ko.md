## 2. 대화 찾기 흐름

- 명칭 정리: `기억 찾기` → **`대화 찾기`**(title: 지난 대화 찾기).
- 좌측 상단 브랜드 ⌕ 아이콘에서도 열림 · 열리면 버튼이 `닫기`, 닫으면 `대화 찾기` 복원.
- 결과의 제목·본문 클릭 → `source.sessionId` + `selectSession(id)` 재사용으로 **그 대화로 이동**
  후 패널 자동 닫힘. 반영하기·되돌리기는 별도 버튼 그대로(이동과 의미 분리).
- 정직한 다음 길: sessionId 없음 / 원본 대화 삭제 → "내용은 반영하기로 쓸 수 있어요" 안내.
  빈 결과 → "찾은 대화가 없어요. 다른 말로 다시 찾아볼까요?"
- 화면 관통: 검색 열기 → `보고서` 17건 → 첫 결과 클릭 → 해당 대화 로드 확인 → 닫힘 확인.

## 3. 최소 설정 허브

⚙(사이드푸터)에서 열리는 오버레이(도구함 스타일 재사용) — **모델 · 메신저 · 도구와 연결 ·
스킬 · 기억과 개인정보 · 모양** + `← 대화로 돌아가기`. 각 영역은 실제 존재 기능만:

- 모델: 기존 `renderModelConnect` 를 통째로 이동(중복 관리 금지 — 준비됨 칩에서는 제거).
- 메신저: 채널 상태(/channels) + 허용목록 관리(도구함과 같은 렌더러 재사용).
- 도구와 연결: 도구함 열기(연결 상태·시험·무효 선언 정리는 도구함 한 곳).
- 스킬: /skills 목록 + 추천 승인. 없으면 "반복되면 후보로 제안 — 자동으로 켜지지 않아요".
- 기억과 개인정보: /overview 선호·기억 행(공통 memAction 통로) + 수명주기 영수증 건수 +
  "원문은 기록에 저장되지 않아요(지문만)".
- 모양: 테마 전환(기존 함수 재사용).
- 준비됨 칩: 상태 표시 + "관리는 설정에서" 링크만(같은 기능 두 화면 관리 금지).
- 온보딩(첫 모델 연결)도 설정 허브 모델 영역으로 통일.

화면 관통: 6개 탭 각각 실데이터 렌더 확인 · 대화로 돌아가기 · 오버레이 바깥 클릭 닫힘.
