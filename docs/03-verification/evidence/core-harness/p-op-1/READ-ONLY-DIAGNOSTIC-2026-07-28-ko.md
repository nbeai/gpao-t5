# P-OP-1 A 읽기 전용 진단 라이브 증거

시각: 2026-07-28

## 검증한 사용자 흐름

사용자 문장: `컴퓨터가 요즘 느린데, 바꾸지 말고 원인만 봐줘.`

현재 연결된 실제 모델로 새 대화를 만들고, 요청을 한 번만 보냈다.

## 관찰 결과

- 일반 답변으로 끝났다. 승인 카드나 대기 상태가 아니었다.
- T5는 읽기 전용 진단을 실제로 실행했고, 원장에는 확인된 실행만 남았다.
- 파일 변경·프로세스 시작·외부 전송은 없었다.
- 답변은 실제 읽기 결과를 근거로 한 설명이었다.

## 이번에 고친 경계

`LaunchAgents` 또는 `LaunchDaemons` 경로를 읽는 것까지 자동 실행 변경으로 분류해 승인으로 보내던 문제를 고쳤다. 이제 실제로 서비스를 올리거나 내리는 `launchctl` 동작만 별도 보호한다. 파일 쓰기는 기존 샌드박스 경계가 계속 막는다.

## 한계와 다음 검증

이 증거는 API 응답·원장 기준이다. 웹 화면을 눈으로 확인한 증거는 아니다. B(자료 탐색·정리)와 C(낯선 외부 업무)는 아직 실제 모델 검증 전이다. 개인 장비의 구체적 상태·명령 전문·세션 식별자는 보관하지 않았다.
