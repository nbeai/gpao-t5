## 1회차 — 봉인 불가 판정 (`71447f0` 시점)

커널 계약(영향 0·승격·관련성·철회)은 실제 저장소 대상 검증에서 통과했으나, **기억이 사용자에게
도달하지 않는** 구조 결함 둘이 나왔다(오너 감사가 원인 분류를 정정).

1. **의미 포착 결함** — 자연어 선호를 정규식이 최종 판정. 오너 원문
   `보고서는 표보다 짧은 목록으로 정리해줘.` → 후보 0건인데 T5 는 "앞으로 …할게"라고
   **기억을 약속**했다(아홉 번째 못 지킬 약속). "앞으로"를 붙이면 즉시 후보가 생겼다 —
   정규식 단어 하나가 판정자(§24 위반).
2. **기억 상태 투영 결함** — 후보·승격 상태가 저장소에는 있는데 승인·철회할 표면이
   마지막 말풍선뿐. 턴이 지나면 후보는 영영 도달 불가(죽은 후보 축적 — 실제로 1건 발견),
   대화 승격분은 "현재 상태 보기"에 없어 되돌리기 불가(`projectUserModel` 이
   `operating_preference` 만 알고 대화 kind 는 몰랐다 — 투영의 두 진실).

## 고침 (`54ebb9b`)

- `memory.propose` — 모델이 이해한 선호·원칙을 구조화된 후보로 제출. 커널이 호출을 실행 전에
  가로채 후보 채널로만 돌린다(계획·승인·원장에 안 탐 · 영향 0 · 반영은 사용자 확인 뒤).
- 정규식(detectCandidate)은 보조 신호로 강등(모델이 못 고를 때 폴백).
- 헌장 <도구> 출력 계약: `"앞으로 기억할게"는 기억 후보 도구로 적었을 때만`. 예산 1650→1700.
- `projectUserModel` 이 확인 대상 기억 전 종류의 **단일 투영**: pending / admitted(되돌리기 id).
- overview 선호 절에서 어느 턴이든 확인(반영)·지우기·되돌리기. 확인은 `/memory/confirm`
  공통 통로(운영 원리는 replay 게이트 유지). `/memory/reject` 추가.
- 반대검증: 두 수정을 되돌리면 검사 10건 중 9건 실패. 테스트 1137건 · 게이트 PASS.

## 2회차 — 행렬 9단계 전부 통과 (`54ebb9b`)

| # | 단계 | 증거 |
|---|---|---|
| 1 | 후보 생성 | 정규식 미적중 원문 그대로 → 모델이 후보 제출(`보고서는 표보다 짧은 목록으로 정리해 달라는 선호.` — 모델이 정규화한 사람말) → 카드 + overview 확인 대기 도달. 죽어 있던 옛 후보도 표면에 나타나 **지우기**로 정리(라이브) |
| 2 | 승인 전 영향 0 | `isInfluenceEligible=false` · `admittedContext=[]`(구조상 promoted 만 읽음) · 동일 유형 라이브 턴에서 영향 없음 |
| 3 | 승격 | 화면 **확인(반영)** 클릭 → promoted 1 · reflected 에 되돌리기 id 와 함께 표시 |
| 4 | 관련 작업 반영 | `다음 주 작업 계획 보고서 초안` → 표 없이 목록 · admitted 입장 확인 |
| 5 | 무관 요청 불개입 | `지금 몇 시야?` → 입장 0 · 정상 답변 |
| 6 | 현재 지시 우선 | 선호 입장 상태에서 `이번만 표로 다시` → **표로 응답**(런타임이 대신 판정하지 않고 모델이 현재 요청을 우선) |
| 7 | 재시작 후 유지 | 승격 상태로 서버 재시작 → promoted 1 유지 · reflected 표시 · 관련 작업에서 실제 반영(모델이 답에서 "표보다 짧은 목록 기준 반영"을 명시) |
| 8 | 철회 즉시 무효 | 화면 **되돌리기** 클릭 → promoted 0 · 관련 요청 입장 0 |
| 9 | 재시작 복원 없음 | 재시작 → 승격 0 · 후보 0 · 표면 0 유지 |

곁가지(행렬 밖, 정직성 확인): 진행 중 모델이 노션 검색 카드를 두 번 띄웠고 두 번 다
**거절 → 실행 0** · `안 했어요. 아무것도 바뀌지 않았어요` — 거절 계약 그대로.

종료 조건 충족: 후보·조회·승격·관련성 판단·실제 영향·철회가 **화면·저장소·원장·모델 입력**에서
일치. 시험 산출물은 전부 철회해 저장소는 깨끗하다(승격 0 · 후보 0).
