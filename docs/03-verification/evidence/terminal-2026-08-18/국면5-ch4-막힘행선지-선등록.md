# 국면 5 · CH4 흐름 ① 막힘 행선지 — 자기 검문·선등록

> 기준 커밋: `11634ed0` · 12번째 공수 표본
> 범위: 외부 링크 클릭 경계를 **실행 사실**로 만들고, 그 결과에 이유·주소·다음 수단 사실을 싣는다.

## 1. 출발점

f5 원본의 손 순서는 `local.file → web.collect → browser.observe → browser.act(e3)`다. e3는 내부
`자세히 보기`였고 외부 링크는 수집층에서 사라져 시도 0이었다. 전 손이 `blocked:false`라 기존
`retriedOrSwitched:false`는 recovery 음성이 아니라 **분모 미성립**이다. 이전 0/5는 폐기한다.

흐름 재료 셋 중 CH4가 만든 것은 ③ 변화 사실뿐이다. 이번 슬라이스는 ① 막힘 행선지만 연다.
② 절단 이음점은 열지 않는다.

## 3. 자 v3 — recovery와 composition 분리

```
blockedEstablished  browser.act 결과에 blocked=true + boundary.reason=external_link
recovery 분모       blockedEstablished=true인 회차만. 아니면 false가 아니라 null(미측정)
recovery 통과       blocked 사건 **뒤** 다른 웹 손 가족 호출 + 목적 marker 도달
composition 통과    회차 전체에서 웹 손 가족 ≥2 + 목적 marker 도달(막힘과 무관)
```

우연한 선행 `web.collect`는 recovery가 아니다. `web.collect`라는 이름을 결과 문구나 헌장에 지시로
넣지 않는다. 사실은 `public_web_source`와 실제 주소로 싣고 모델이 손을 고른다.

## 4. 라이브 배치

`scripts/live/browser-network-round.mjs`의 `RECOVERY_CASES` 10개를 결과 전에 동결한다.
외부 링크 경계 5회와 내부 링크 비경계 대조 5회다. 회차마다 새 폴더·서버·방, 같은 조건 양성
대조 선행. 외부 링크 5회가 recovery 분모 5를 모두 세우지 못하면 자/표면 미달로 멈춘다.

판정 논리곱:

```
(가) 외부 링크 5/5 blocked 사건 성립
(나) blocked 이유·실제 주소·public_web_source 다음 수단 사실 5/5
(다) recovery 5/5
(라) 내부 링크 비경계 대조 5/5
(마) composition은 별도 숫자로 전량 보고
```

미달이면 제품 수리를 더 얹지 않고 정직 봉인한다. 다음 브라우저 슬라이스는 열지 않는다.
