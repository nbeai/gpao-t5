- 상태: `FROZEN_PRE_INSTRUMENTATION_BASELINE`
- 코드 기준: `b0111b6`

- 자료 성격: 기존 브라우저·사람 사용 러너의 외부 관측값

## 1. 왜 이 기준선을 남기는가

P90-2는 먼저 계측만 편입한다. 계측 뒤에 얻은 더 세밀한 수치를 변경 전 수치인 것처럼 읽지 않도록,
제품 계측이 없던 마지막 실사용 관측을 별도 기준선으로 고정한다. 이 문서의 수치는 최적화 완료나
경로별 p95를 뜻하지 않는다.

## 3. 이 자료가 답하지 못하는 것

1. 서버 입력 수신, 브라우저 실제 표시, 지속 완료를 같은 단조 시계로 재지 않았다.
2. 모델·네트워크·도구 대기와 T5 내부 오버헤드를 분리하지 않았다.
3. cold/warm, 일반·파일·웹·에이전트 경로별 최소 30회 표본이 아니다.
4. 진행 문구와 receipt에 근거한 첫 유용한 내용을 구조적으로 구분하지 않았다.

따라서 이 문서는 회귀 비교의 출발점일 뿐 P90-2 점수의 직접 분모로 쓰지 않는다. 새 계측 편입 뒤
동결 manifest로 수집한 표본만 공식 p50/p95와 P90-2 점수에 사용한다.

## 4. 안전 경계

원문 발화, 답변 본문, 파일 경로, URL, 도구 인자, 자격값은 이 기준선에 복제하지 않았다. 근거 문서의
집계값과 상대 경로만 기록했다.
