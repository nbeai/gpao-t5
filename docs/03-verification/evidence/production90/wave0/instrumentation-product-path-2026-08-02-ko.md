# Production 90 Wave 0 계측 제품 경로 증거

- 상태: `IMPLEMENTED_AND_PRODUCT_PATH_VERIFIED`
- 역할: Codex 5.6 Sol 겸임 구현·자체검증 — 독립 감사 필요
- 공식 점수 사용: 금지(배선 제품 관통 1회)
- 공식 기준선: 경로별 cold/warm 최소 30회 수집 뒤 별도 산출

## 1. 편입한 사실

1. 서버 사건은 입력 수신, 스트림 연결, 큐 진입·시작, 첫 진행, 첫 답, 지속 완료, SSE 완료를 같은
   `measurementId`로 기록한다.
2. 브라우저 사건은 실제 paint 뒤 첫 진행 표시, 첫 답 조각 렌더, 서버 지속 결과의 최종 DOM 투영 완료를
   같은 신분에 결합한다.
3. 모델·도구 await는 겹친 구간을 중복 합산하지 않고 구간 합집합으로 계산한다. T5 오버헤드는 지속 완료
   시간에서 이 합집합을 뺀 값이다.
4. 저장 스키마는 원문 발화·답변·파일 경로·URL·도구 인자·자격값을 받지 않는다. 브라우저 보고 API도
   고정된 네 필드 외 입력을 거부한다.
5. 계측 저장 실패나 브라우저 보고 실패는 대화 실행을 실패시키지 않는다.

## 2. 실제 브라우저 제품 관통 1회

격리 데이터 폴더와 로컬 제품 서버를 사용해 실제 Work Chat 화면에서 한 턴을 입력했다. 이 회차는 계측
배선 검증용 stub 모델 회차이며 모델 성능·제품 p95 표본으로 쓰지 않는다.

| 사건 | 입력 수신 뒤 경과 |
|---|---:|
| 스트림 연결 | 3.942ms |
| 큐 시작 | 5.671ms |
| 서버 첫 진행 | 6.614ms |
| 브라우저 첫 진행 표시 | 26.1ms |
| 서버 첫 답 | 34.363ms |
| 서버 지속 완료 | 37.527ms |
| SSE 완료 | 39.422ms |
| 브라우저 첫 유용 내용 | 75.9ms |
| 브라우저 최종 투영 완료 | 76.3ms |

모델 외부 대기는 0.244ms 1회였고 도구 대기는 없었다. 계측 레코드에 원문 발화·답변·경로·URL·도구
인자는 없었다. 서버 종료 뒤 T5 리스너는 남지 않았다.

## 3. 반증과 회귀

| 검증 | 결과 |
|---|---|
| 계측·점수 계약 집중 검사 | 29/29 PASS |
| 스트리밍 포함 집중 검사 | 55/55 PASS |
| 전체 회귀 | 1,927/1,927 PASS |
| 돌연변이 | 240/240 PASS, 활성 소스 지문 전후 동일 |
| 계획·문서·작업공간 게이트 | 전부 PASS |

새 돌연변이 다섯 종은 임의 원문 필드 수용, 겹친 외부 대기 중복 합산, 브라우저 첫 사건 덮어쓰기,
계측 신분 미전달, 화면 계측 API 임의 필드 수용을 각각 깨뜨렸고 지정 검사가 모두 잡았다.

## 4. 주장하지 않는 것

- 이 한 회차는 실제 모델·네트워크·파일·웹·에이전트 경로의 p50/p95가 아니다.
- 현재 편입 범위는 Work Chat 웹 SSE 경로다. 비스트림 `/turn`, 채널, 예약 자동화 경로까지 계측됐다고
  주장하지 않는다.
- `first_grounded_content`는 현재 첫 답 조각이 실제 DOM에 그려진 사건이다. 별도 부분 영수증 이벤트는
  아직 제품에 없다.
- 외부 대기는 모델·도구 adapter await 경계의 시간이며 순수 네트워크 시간만을 뜻하지 않는다.
