- 기준 커밋: `636ed72`
- 작업선: `codex/production90-score-hardening`

## 1. 수정 전 실패

기존 집계기는 결과의 `metricId`와 상태만 모았다. 등록되지 않은 시나리오, 서로 다른 manifest와 build
신분, 빈 증거 참조를 가진 PASS를 각 지표 분모만큼 복제해도 P90 네 작업선, 18개 평가 항목, 일곱 코어가
모두 100점으로 계산됐다. 또한 73개 지표 중 18개는 어떤 사전 등록 시나리오에도 귀속되지 않았다.

## 2. 보강한 계약

1. 실행 bundle을 JSON schema로 실제 검증하며 알 수 없는 필드와 원시 문자열 증거를 거부한다.
2. 실행은 등록된 시나리오와 `scenarioSampleIndex`에, 결과는 등록 지표와 `sampleIndex`에 묶인다.
3. 같은 `runId`, 시나리오 표본, 지표 표본은 두 번 들어갈 수 없다.
4. manifest digest와 시나리오 환경 계약 digest는 정본에서 계산해 대조한다.
5. build digest는 bundle 자기신고가 아니라 호출자가 별도로 고정한 신뢰 기준과 대조한다.
6. 지표별 요구 증거 종류와 content digest가 모두 있어야 하며 모델 증거 지표는 모델 영수증도 필요하다.
7. 구조 책임·호환·변경 국소성 감사를 29번째 결정적 시나리오로 분리해 73개 지표의 미귀속을 0으로 만들었다.

## 3. 반대시험과 게이트

- 수정 전 점수 계약 집중 검사: 3건 실패(18개 미귀속, 검증 함수 부재 2건)
- 수정 후 점수 계약 집중 검사: 18/18 PASS
- 전체 회귀: 1,937/1,937 PASS
- 돌연변이: 247/247 PASS, 활성 소스 지문 전후 동일
- 신규 돌연변이: 미등록 시나리오, manifest 불일치, 신뢰 build 불일치, 지표 표본 중복, 증거 없음,
  미완료 시나리오 회차, 측정 시나리오 없는 지표의 일곱 계약

## 4. 남은 경계

이 보강은 점수 입력의 구조와 귀속을 검증한다. 증거 파일 자체의 독립 진위 판정과 실제 사용자·외부 환경
관찰은 기존 계약대로 독립 감사가 맡으며, 감사 PASS가 점수를 추가하지 않는다. 공식 점수와 90점 선언은
독립 감사 및 경로별 사전 등록 표본 수집 전에는 금지한다.
