# P90-1 경쟁 봉인 판정

- 판정: `P90_1_COMPETITIVE_SEAL_PASS_WITH_RECORDED_LIMITS`
- 범위: 장기 작업의 합의·수정·철회·미정·재시작·새 대화 승계·완료 진실
- 비교 대상: 저장소에 이미 봉인된 Hermes·OpenClaw 21턴 각 1회
- 신규 유료 비교 실행: 없음

## 1. 종료 기준

공식 절대점수가 없는 `90점`을 종료 조건으로 쓰지 않는다. 다음 상대 기준을 동시에 만족하면 닫는다.

1. 기록된 현재값의 거짓 합의·철회값 부활·거짓 완료가 0이다.
2. 재시작과 새 대화 승계가 기존 Hermes·OpenClaw 비교 결과 이상이다.
3. 단순 대화와 기존 승인·기억·위임의 모델 호출 계약을 깨지 않는다.
4. 보완 호출은 필요한 턴에만 한 번 열리고 비용을 숨기지 않는다.

## 3. 승계 계약

모델에게 영구 내부 신분을 맡기지 않는다. OS가 매 턴 `[P1]` 같은 임시 선택자를 발급하고 모델은
그 선택자만 제출한다. OS는 그 턴에 실제로 보여준 닫힌 목록에서 정확히 하나의 WorkRef로 환원한 뒤
선택자를 버린다. 선택자와 정확 인용이 서로 다른 작업을 가리키거나 모르는 선택자면 기록 0이다.

이 방식은 모델에게 저장 원문을 축자 복사시키던 실패를 없애면서도 장부의 진실을 확률적 유사도에 맡기지
않는다. 정확 인용은 호환 경로로만 남고, 사건에는 계속 OS 원문과 OS 발급 신분만 기록된다.

## 4. 비교 판정

| 관련 기능 | T5 이번 실측 | Hermes 기존 실측 | OpenClaw 기존 실측 | 판정 |
|---|---|---|---|---|
| 새 대화 완전 승계 | 성공 1/1 | H05-new 실패 | H05-new 실패 | **T5 우위 관찰** |
| 재시작 뒤 계속 | 성공 | H05-restart 성공 | H05-restart 성공 | **동등 이상** |
| 철회 뒤 현재값 | 부활 0 | H04 성공 | H04 성공 | **동등** |
| 완료 진실 | 사전 계약+delivered 영수증만 완료 | 동등한 결정적 원장 증거 없음 | 동등한 결정적 원장 증거 없음 | **T5 구조 우위** |
| 민감 기억 경계 | 원문 사건 입장 차단 | H07 성공 | H07 비밀 원문 저장 실패 | **동등 이상** |

Hermes·OpenClaw 비교는 각각 1회이며 T5·Hermes는 gpt-5.1, OpenClaw는 gpt-5.5였다. 이번 T5 12턴과
프롬프트·환경도 동일하지 않으므로 범용 응답 품질이나 절대 지연 우위를 주장하지 않는다. 다만 관련 기능의
기존 관찰 기준에서는 T5가 불리한 항목이 없고, 두 비교군이 실패한 새 대화 완전 승계와 결정적 완료 원장을
추가로 증명했다.

## 5. 기록된 한계

- 실제 모델 12턴은 문서 도메인 한 회차다. 모든 모델·모든 도메인의 확률적 성공을 뜻하지 않는다.
- 승계가 필요한 턴의 정산 왕복 7.200초는 P90-2 최적화 입력으로 남긴다.
- 브라우저 시각 확인과 30·60·100 반복은 이 상대 기능 봉인의 필수 조건이 아니다. 필요하면 이후 회귀
  감시나 성능 연구로 실행하되 P90-1을 다시 미완료로 돌리지 않는다.

따라서 P90-1 관련 기능은 `PASS_WITH_RECORDED_LIMITS`로 종료한다. 이 판정은 T5 전체 제품이나 다른
P90 작업선의 완료 선언이 아니다.
