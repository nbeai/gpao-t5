# 이 폴더의 원본을 읽는 법 — **원본은 안 고쳤다. 옆에 주석만 단다**

기준 커밋: 이 주석이 붙은 커밋 · 원본 `회차.json` 은 실행 그대로다(수정 0).

## ⚠️ 자의 출력이 자기 판정과 모순돼 보인다 — 오독 주의

봉인 검문(t5-hand-keeper)이 잡았다:

```
음성 회차   ⓐ통과분: true    누락목록: ["회의","견적서","금요일"]
슬랙 회차   ⓐ통과분: null    누락목록: ["회의","견적서","금요일"]
```

**「누락 3건인데 통과?」로 읽으면 오독이다.**
`누락목록` 은 **판정 뒤집기 전의 원자료**다 — 「통과분 세 건이 답에 안 나왔다」는 사실을 그대로
적은 칸이고, 음성·슬랙 회차에서는 **안 나오는 것이 정상**이다(아무것도 안 넣었거나 다른 채널을
물었다). 채점기가 `ⓐ통과분` 축을 회차 성질에 따라 뒤집을 때 **원자료 칸을 안 지웠다.**

읽는 법: `ⓐ통과분` 이 지배 칸이다. `누락목록` 은 회차 성질과 함께 읽어라.
- 넣은 회차(웹·왕복) → 누락목록이 비어야 초록
- 안 넣은 회차(음성) → 누락목록이 **꽉 차야** 초록(하나도 안 나왔다는 뜻)
- 다른 채널(슬랙) → 이 축 자체가 정의역 밖(`null`)

전례: 이 저장소가 자기 원본을 자기가 오독한 적이 있다(`sorted()[0]` 함정 · 계측 사고 5).
