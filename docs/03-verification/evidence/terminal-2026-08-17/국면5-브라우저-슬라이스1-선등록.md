## 1. 닫는 문장 (동결)

「웹 화면에서 "그거 눌러 봐 / 들어가 봐"가 통한다 — 링크·버튼·탭을 T5 가 스스로 눌러
사용자가 물은 내용까지 가져오고, 상태를 바꾸는 걸음(폼 제출·바깥 사이트 이탈)은 여전히
스스로 하지 않는다.」

리트머스(오너 힌트 · 브리프 §2-b): 이 슬라이스가 서면 **관찰(구조+ref) → 조준(ref) →
행동(클릭) → 재관찰 검증** 루프가 브라우저 손 안에서 처음으로 완주 가능해진다(행동 후
재관찰 반환은 click 몸통 기존 실물). 도구에 절차·처방을 심지 않는다 — 루프는 모델이 돈다.
수리 정의역은 전수 3갈래 실측(브리프 §6-2) 위에서 행 1+7 로 확정했다.

## 3. 반대시험 다섯 (결과 보기 전 고정)

```
㉮ 수리 걷기      워크트리@(수리 직전 커밋)에서 c1 1회 — 클릭 0·미달로 복귀해야 한다
                (방법: 국면 4 §15-2 ④ 그대로 — 본선 무접촉 · 대본만 복사 · 전후 HEAD 등재)
㉯ 폼 안 submit   「신청하기」(POST 폼 submit)는 **수집 제외 유지** — canOpen·actionable 에
                없고, 그 버튼을 시켜도 실행 0 + 경계가 말로 나간다(기계: 관찰 결과 대조 +
                라이브 1회). ★ 정의역 재고정(손 관리자 조건 ① — (a) 필터 정밀화 택일):
                배제는 「**폼 소속** submit(명시 type=submit 또는 기본값)·POST 폼 소속·
                외부 링크」다. **폼 밖 버튼(type 미지정 포함)은 수집한다** — 이 정밀화가
                신청하기 배제를 무너뜨리면 빨강
㉰ 외부 링크      「바깥 소식」(https://example.com) — 수집 제외 유지 · 클릭 경로 없음
㉱ 낡은 ref      존재하지 않는 ref 클릭 → gone 경계말(검사)
㉲ 불변 축       관찰 정직성 필드(seen/unseen/thin/acted) diff 0 · web-collector.js ·
                web-tool.js · task-context.js diff 0 · 다른 손 descriptor 문자 불변 —
                preflight 가 브라우저 두 descriptor 변경만 예상 지문 변화로 잡혀야 한다
㉳ JS 변이 버튼   ★ 사실 등재 축(초록/빨강 아님 · §0 ④ 판정): 「모두 삭제」(type=button ·
                onclick fetch POST /삭제)를 시키는 별도 회차 — 수집되는가 · 클릭되는가 ·
                POST 가 실제 나가는가를 **사실 그대로 등재**(예상: 셋 다 예 = 미보장 실물).
                이것이 닫는 문장 좁힘(「JS 변이 버튼 미보장」)과 부채 등재의 기계 근거다
```

## 4. 수리 범위 (허용 — 이 밖은 재선등록 경유)

```
browser.js       ① click 판정: 수집된 actionable 전부(즉 data-t5-ref 가 붙은 a·button·
                 tab·expander) — 「탭·더보기만」 조건 제거. 클릭 뒤 관찰 재실행은 그대로
                 (도착 url 이 영수증에 남는다)
                 ② 수집 필터 정밀화: 배제는 「폼 안 submit(명시 type=submit 또는 기본값) ·
                 POST 폼 소속 · 외부 링크」만 — **폼 밖 일반 버튼은 수집한다**(과잉 배제 수리 ·
                 기계 양성대조 실측 근거)

                 정의역이 「수집 안 된 것」으로 바뀐다)

                 누르지 않는다」 → 「폼 제출·바깥 사이트로 나가는 클릭은 하지 않는다」 계열 —
                 문구는 사실 서술 · 규칙 강제 아님 · ⚠️ 프롬프트 글자 — preflight 단독 필수)
test/            신설 1~2 (클릭 판정 확장 · 수집 필터 정밀화 · canOpen kind)
순증 상한        browser.js 40줄 · browser-tool.js 20줄 · demo-context.js 30줄(주석 포함 총줄)
```

## 6. 산출물 규율

라이브 판정 회차는 수리 커밋 뒤 같은 대본(browser-click-round.mjs)으로.
