```
요청     보좌관(개발보좌관0817) 전달 · 오너 원칙 둘과 함께 · **수리 아님 · 사실만 실측해 등재**
기준 커밋 ec18a3b7 (재는 법: git rev-parse --short HEAD) · 제품 코드 0줄
성격     읽기 실측. 이 문서는 **판정이 아니라 사실**이다 — 갈래는 다음 착수 검문 경유
```

## 답 — **집행 경로는 없다. 그리고 그것은 결손이 아니라 「선언된 경계」다**

### 1. 채널 입구는 `approve`/`reject` 를 **아예 안 싣는다**

```
웹 계약   server.js:7   POST /turn → { sessionId, text|approve|reject, ... }
채널 호출 server.js:4007-4014  runTurn({ text, source, triggerSignals, channelPolicy,
          channelConnected, channel, channelLabel, turnRef }, ctx)
          ⇒ **approve·reject 인자가 없다**
```

### 2. 자연어 승인 경로도 **없다** — 집행은 구조 id 로만 된다

```
src/kernel/turn.js:1042   const saved = ctx.pending.get(input.approve);
src/kernel/turn.js:1116   const 거절된것 = ctx.pending.get(input.reject);
```
`ctx.pending` 소비자 전수(turn.js:670·902·1042·1049·1070·1116·1124·2099·3382·3678)에
**발화 문자열로 pending 을 집행하는 자리는 0건**이다. 「네」 한 마디는 집행이 아니라 새 턴이다.

### 3. 그런데 **막아 둔 것**이다 — 사유가 코드에 적혀 있다

```
src/surface/server.js:3843-3844
  // 승인이 필요한 일은 채널에서 자동으로 실행하지 않는다. 무엇을 하려는지·왜 멈췄는지만 알린다 —
  // 승인은 T5 화면에서 받는다(밖에서 "네" 한 마디로 외부 효과가 나가면 안 된다).
```
⇒ 등급은 **「선언된 경계」**다(정본 순서 4 ⑥ 과 같은 등급). **결손·구멍으로 적으면 틀린다.**

### 4. 왕복의 **절반은 이미 서 있고 검사가 문다**

```
test/channel-approval-resume.test.js:70  「방에서 시킨 일을 화면에서 승인하면, 결과가 방으로 돌아간다」
test/channel-approval-resume.test.js:99  「화면에서 시작한 일은 방으로 밀지 않는다(채널에 묶인 세션이라도)」
server.js:4044  채널 턴의 pendingApprovals 는 그 방 세션에 **지속된다**(보좌관 실측 확인)
server.js:3849  요청이온자리로 — 다른 표면에서 끝난 일의 결과를 요청이 온 자리로 돌려보낸다
```
즉 **방 → 화면(승인) → 방** 은 성립한다. **방 → 방** 만 경계로 막혀 있다.

## ★ 사실로 등재하는 충돌 — 판정하지 않는다

오너 원칙 ①(보좌관 전달 · 2026-08-17): 「외부 메신저는 알림 채널이 아니라 **로컬 기반 T5를
사용자가 밖에서도 정상 작업하게 하는 장치**」.

그런데 위 §3 의 선언된 경계는 「**승인은 T5 화면에서 받는다**」이다.
⇒ **승인이 필요한 일은 밖에서 끝나지 않는다.** 밖에서 정상 작업이 안 되는 구간이 실재한다.

이 둘은 **정면으로 부딪힌다.** 다만:
- 경계 쪽 논거는 안전 축이다(「밖에서 "네" 한 마디로 외부 효과가 나가면 안 된다」) — 헌장·안전
  바닥 계열에 닿는다. **경계를 무르는 것은 안전 성질을 바꾸는 일**이다
- 원칙 ① 은 오너가 방금 선언한 **방향**이다

**나는 여기서 판정하지 않는다.** 실측만 등재하고, 갈래 설계는 다음 슬라이스 착수 검문 경유다.
갈래 후보를 이름만 적어 둔다(설계 아님 · 어느 것도 고르지 않았다):
```
(가) 경계 유지 + 밖에서 「승인 대기 목록 조회」만 — 집행은 화면
(나) 밖에서 집행하되 **신분 강화**(허용목록 + 카드 id 명시 + 되돌릴 수 있는 것만)
(다) 승인 카드가 뜨는 정의역 자체를 줄여 밖에서 걸릴 일을 줄인다
```
어느 갈래든 **안전 바닥(SAFETY_FLOOR_KINDS)에 닿으므로 착수 검문 없이 손대지 않는다.**

- **라이브 0회** — 이 실측은 전부 코드·검사 층이다. 「텔레그램에서 승인 시도 → 무슨 답이
  돌아오나」는 안 돌려봤다. 밖에서 「네」라고 했을 때 사용자가 **무엇을 보는지**가 미측정이다
