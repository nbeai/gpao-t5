## 2. 실제 원인 — 커널이 사용자 입으로 말한다

`node scripts/s0/show-prompt.mjs "안녕"` 이 찍은 것:

```
[user]
[T5가 먼저 맡을 수 있는 일]
- 웹 자료 수집: 공개 웹 자료를 직접 찾아 읽고, 읽은 근거를 남긴다.
- 로컬 파일: 작업 폴더 의 자료를 직접 읽고 정리한다.

안녕
```

능력 목록이 **시스템 프롬프트가 아니라 사용자 메시지 안에** 있다([model-provider.js:274](../../../../src/runtime/model-provider.js:274)).
모델은 사용자가 그렇게 말했다고 읽는다. 그래서 인사에 능력을 읊었다. **모델 잘못이 아니다.**

같은 자리에 커널이 쓰는 블록이 **모두 15개**다. 진짜 사용자 발화는 **맨 마지막**에 붙는다(315행).

```
[다른 대화에서 이어받을 수 있는 작업]  [저장된 기본값]  [직전 답이 놓고 쓴 것]
[이번 턴 실행 사실]  [바깥 자료에 닿는 현실]  [이번 턴의 연결 입력·확인 사실]
[T5가 먼저 맡을 수 있는 일]  [막힌 것과 다음 길]  [완료 계약 판단]  [이번 결과 형태]
[이번 요청의 행동 판정]  [턴 정산 사실]  [이번 답의 완료 기준]  [원장 대조]
                                                              ← 그리고 사용자 발화
```

**원리 ③ 위반의 가장 나쁜 형태다.** 능력은 도구 목록이 말해야 하는데, 커널이 사용자 목소리로 말한다.
시스템 프롬프트에는 *"묻지 않은 능력 나열 금지"* 가 적혀 있다. **말과 행동이 반대다.**

이 구조는 오너가 겪은 다른 증상 하나도 설명한다 — 깃허브 저장소를 물었는데 네이버 메일 답이 나온 건
`[이번 턴 실행 사실]`(187행)이 앞 턴 도구 결과를 사용자 메시지에 실어 보내기 때문일 수 있다.
**아직 재현으로 확정하지 않았다 — 기전이 있다는 것까지가 지금의 사실이다.**

## 2-1. 확정하지 못한 반쪽

오너가 받은 인사 답의 뒷부분 *"메일·텔레그램·슬랙 같은 건 지금은 직접 연결은 안 된 상태네"* 는
**프롬프트 어디에서도 찾지 못했다.** `operatorReality` 는 쓸 수 있는 손만 담고, `limits` 는 비어 있고,
도구 스키마도 `executable` 만 싣는다. **모델이 빈칸을 그럴듯하게 메운 것으로 보이나 확정 못 했다 — 관측이다.**

## 3. 열린 질문의 답 — 모델은 왜 `from: "Documents"` 를 골랐나

**커널은 안 막았다.** 스키마에 `from … 비우면 홈` 이라고 적혀 있고, `local.locate` 는 `from` 이 비면
홈 전체를 훑는다([local-locate.js:161](../../../../src/runtime/local-locate.js:161)).

다만 그 설명은 `from` 을 다섯 번 강조하고("이름을 그대로 from 에", "from 을 바꿔 다시"),
**"비우면 홈"은 파라미터 설명 맨 끝에 한 번**뿐이다. 제약이 아니라 **유도**다.
→ 고치는 자리는 설명이지 구조가 아니다. 후속 장부에 적고 해당 단계에서 다룬다.

## 4. 곁가지 — 계측기 자신에 있던 구멍 둘

**① 주 경로에 계측기가 없었다.** 덤프는 `chatgpt` 클라이언트에만 있었고, 오너가 쓰는
provider 경로에는 아예 없었다. 그래서 라이브를 볼 방법이 없었다.

**② 예전 덤프는 비밀을 원문으로 디스크에 썼다.** `GPAO_T5_DEBUG_PROMPT` 가 system·user 를
그대로 파일에 이어 붙였다. 이제 `prompt-dump` 하나로 모으고 가림을 건다.

**③ preflight 가 한글 파일명을 못 봤다(별건).** git 은 비ASCII 경로를 따옴표로 감싸 8진 이스케이프한다.
`변경파일` 이 줄 단위로 읽고 있어서 무시 필터(`test/`·`.md`)가 **전부 빗나갔다.**
이 저장소는 한글 이름이 대부분이라 구멍이 컸다. `-z` 로 고치고, **검사가 통과하면서 깨져 있던 것**을
잡는 반대시험을 더했다.

## 5. 이 결과가 계획에 미치는 것

**S1 의 표적이 바뀐다.** "`blocked` 를 뺀다"가 아니라 —

> **커널이 사용자 입으로 말하는 것을 멈춘다.**

`blocked` 는 애초에 인사 턴에 실리지도 않았다. 진짜 병은 15개 블록이 사용자 발화 앞에 붙는 구조다.
사실은 시스템 프롬프트(안정) 또는 도구 결과(모델에게 돌아가는 데이터)로 가야 한다 — 사용자 목소리가 아니라.

**불변식 B 도 여기서 걸린다.** 이 블록들은 사용자 턴에 있어 **캐시에 얹히지 않는다.** 매 콜 새로 지불한다.
