# F-11 라이브 브라우저 실측 (2026-08-09 · 격리 방 · gpt-5.1)

절차: 격리 방(새 방·새 상태 · 실사용 상태 자리 불가침) 위 라이브 서버(4333) → 앱 내
브라우저로 화면 접속(쿠키는 첫 페이지 로드가 자동 부여) → ⑦ 발화를 채팅 입력으로 직접
전송 → 화면 실물 확인.

사슬 여섯 걸음 전부 기계 사실:
1. 모델이 자동화 채널을 부름(원장 · automationProposal 생성)
2. 서버가 후보 저장 — state/automation.json 실물(candidateId · kind: weekly · state:
   proposed · approved: false) → 본 폴더 automation.json 에 사본
3. /turn 응답에 automationProposal 실림(session.json 사본)
4. **화면에 카드가 떴다** — "이 작업을 자동으로 반복할까요?" + 발화 원문 + "승인 전엔
   아무것도 실행하지 않아요. 켜도 범위·만료(기본 30일)·취소가 있고 실행은 원장에 남아요."
   + [자동화 설정]/[아니요] (page text 원문 캡처는 아래)
5. [자동화 설정] 클릭 → 404 아님 — "이 일을 자동으로 맡길 준비가 아직 안 됐어요. 같은
   일을 한 번 저와 함께 해 보면 그걸 배워서 반복할 수 있어요." (스킬 0 방의 정직한 다음 길)
6. jobs: [] — 등록 실물은 스킬 학습 선행. 거짓 등록 없음.

⑦ 판정칸 상시 규칙(PM 지시)의 기계 대조 자리: 말(답) + automation.json 의
candidates(후보 실물)·jobs(등록 실물).
