## 3. 차단 결함

### TG5-CX-01 · 발화 출처를 명시적 선호 의도로 오인한다

- **등급:** P1 · TG-5 봉인 차단
- **재현 원문:** `“보고서는 항상 글로 받는 게 좋아”라고 내가 말한 적 있어?`
- **실제 결과:** `detectCandidate()`가 이 질문 전체를 `preference + user_utterance`로 만들고,
  `autoApplicable()`은 `explicit_reversible`로 통과시켰다. 실제 `/turn → /memory` 생산 경로에서도
  질문 전체가 `memoryAutoApplied`로 표시되고 `promoted`에 저장됐다.
- **영향:** 인용·질문·부정처럼 사용자가 선호를 선언하지 않은 문장도 장기 기억이 되어 이후 대화에
  영향을 줄 수 있다. `model_proposal`과 사용자 발화를 구분했지만, 사용자 발화 안의 의도는 아직
  구분하지 못한다.
- **위반 계약:** 결정문 §12의 `explicit` 조건, 현재 지시 우선, 말귀를 정규식 판정으로 되돌리지
  않는다는 최상위 원칙.
- **종료 조건:** 명시 선언·질문·인용·부정·철회가 실제 생산 경로에서 서로 구분되고, 선언만 자동
  반영되며 나머지는 장기 영향 0인 양방향 증거.

### TG5-CX-02 · 한 묶음만 처리하고 모든 관찰을 완료 처리한다

- **등급:** P1 · TG-5 봉인 차단
- **재현:** 한 세션에 서로 다른 subject의 실패 관찰 두 묶음을 남기고 서버를 재시작했다.
  저장 관찰은 4건이었지만 첫 부팅에서 모델에 전달된 것은 `파일-A` 묶음 2건뿐이었다.
  checkpoint는 곧바로 4까지 전진했고, 두 번째 재시작에서는 `파일-B` 묶음이 한 번도 처리되지 않았다.
- **코드 사실:** 추출기는 `groupObservations()` 결과 중 점수가 가장 높은 묶음 하나만 처리한다.
  완료 지점은 그 묶음의 신분이 아니라 전체 `events.length`로 전진한다.
- **추가 정합성:** checkpoint 읽기는 모든 오류·손상을 빈 상태로 취급하고, 쓰기 실패도 호출자에게
  드러내지 않는다. 따라서 현재 검사는 정확히 한 번 처리가 아니라 “파일에 숫자가 생겼고 pending이
  비었다”만 확인한다.
- **영향:** 처리하지 않은 성장 근거가 재시작 뒤 영구히 건너뛰어진다. 반대로 checkpoint I/O 실패
  때는 완료한 근거가 중복 처리될 수 있어 `exactly once` 양쪽이 모두 성립하지 않는다.
- **위반 계약:** 결정문 §6 백그라운드 불변식 1·4, §8의 미처리 checkpoint부터 정확히 한 번 재개.
- **종료 조건:** 서로 다른 여러 묶음, 처리 중 중단, checkpoint 읽기·쓰기 실패를 포함해 각 묶음이
  누락·중복 없이 처리되고 완료 지점이 실제 처리 단위와 일치하는 새 서버 관통 증거.

### TG5-CX-03 · 실제 `M1 → M2` 생산 수명주기가 아직 닫히지 않았다

- **등급:** P1 · TG-5 봉인 및 TG-5B 진입 차단
- **제출자 공개 사실:** replay suite 다섯 축은 통과하지만, 먼저 만들어진 후보와 나중의 명시 지시를
  결합해 확인 사실로 만드는 생산 경로가 없다. 후속 추출은 duplicate가 되어 기존 세포의 확인
  상태를 바꾸지 못한다.
- **독립 확인:** 제품에서 `ConfirmationStore.record()`를 소비하는 경로가 없고, 자연어 경험에서
  시작해 저장된 registry의 M1이 M2가 되는 관통 검사가 없다. 구조 감사는 호출 존재 개수만으로
  `m1_replay_m2_production_lifecycle`을 계속 PASS한다.
- **영향:** 핵심 성장 수명주기가 멈춰 있어도 구조 감사가 완료를 보고한다.
- **위반 계약:** 결정문 §8의
  `자연어 경험 → Observation → M1 → replay → M2 → snapshot → 다음 턴 admission`.
- **종료 조건:** 수동 M2 fixture 없이 실제 사용자 경험과 저장 근거만으로 M1이 M2로 전이되고 다음
  게시본에 나타나며, 해당 경로가 끊기면 구조 감사도 실패하는 생산 관통 증거.
