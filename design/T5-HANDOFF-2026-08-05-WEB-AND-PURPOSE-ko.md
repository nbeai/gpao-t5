## 2. 오너가 나를 고친 지점 — 이게 제일 값지다

내가 오늘 같은 실수를 **네 번** 했다. 다음 세션은 여기서부터 시작하면 시간을 아낀다.

### ① 내 원칙을 사용자 목적 위에 뒀다 (세 번)

| 내가 한 것 | 사용자가 원한 것 | 오너 지적 |
|---|---|---|
| "여기서 잘렸습니다" 안내를 붙임 | 증시 정보 | *"잘렸습니다라고 안내하는 게 무슨 소용이야"* |
| robots.txt 를 지켜 멈춤 | 증시 정보 | *"robots 는 법적 강제가 아니야"* |
| 커널이 정직하게 `ok`/`shell` 판정 | 증시 정보 | *"니들이 정한 원칙들이 우선이 아니라고!!!!"* |

**교훈:** 정직·안전·규율은 **낼 수 있는데 안 내고 대신 하는 말**이 아니다. 정말 못 냈을 때 쓰는 것이다.

### ② 재료 층만 고치고 프로세스 층을 안 봤다

하루에 다섯 번 고쳤는데 **전부 "어떻게 읽는가"** 였다 —
엔티티 → 심긴 JSON → div 내용 → 벽 판정 → 다음수단.
오너: *"날씨 막히면 날씨 고치고 증시 막히면 증시 고치는 방식은 지양해야지."*

### ③ 라이브를 오너에게 시켰다

매번 회귀·돌연변이까지만 하고 *"서버 다시 띄우고 물어봐 주세요"* 로 넘겼다. 그때마다 오너가
대신 돌려 보고 **여전히 틀린 답**을 가져왔다. **§4의 방법으로 직접 돌려라.**

### ④ 비교군을 안 봤다

오너가 세 번 말했다: *"클로드코드 너 자신에게, 혹은 헤르메스에게 직접 같은 질문을 해보고
그 작동원리와 프로세스의 힌트를 얻으라고."* 실제로 해 보니 차이는 도구가 아니라 **순서**였다
(§3). 짐작 말고 **실제로 돌려서** 비교해라.

### ⑤ 이 문서를 읽었다고 안심하지 마라 — 읽는 것으로는 안 막힌다

오너 질문: *"새 세션이 이 문서를 읽으면 확실히 더 잘 하겠지?"* **아니다.**

나는 세션 시작에 정경 문서를 전부 읽었고, §0 과 **같은 말이 이미 기억에 두 개** 있었다
(`첫번째-목표는-동작하는-제품이다` 7-30 · `대리지표를-결과로-세우지-말것` 8-03).
다 읽고 다 로드된 상태에서 **같은 원칙을 네 번 어겼다.**

무엇이 나를 잡았는지 보면 더 분명하다:

| §0 위반 | 문서가 잡았나 | 검사가 잡았나 | 실제로 잡은 것 |
|---|---|---|---|
| "잘렸습니다" 안내 | ✗ | ✗ | **오너** |
| robots 지키고 멈춤 | ✗ | ✗ | **오너** |
| 커널 판정 우선 | ✗ | ✗ | **오너** |
| 재료 층만 다섯 번 | ✗ | ✗ | **오너** |

**네 건 다 검사는 초록이었다.** §0 위반은 회귀 2,644개와 돌연변이 362개를 전부 통과한다 —
T5 가 *"직접 찾아보세요"* 라고 답해도 지금 저장소에서 빨개지는 것은 **하나도 없다.**

문서는 **아는 것**을 돕지 **고르는 순간**을 못 잡는다. 결정은 늘 구체적인 자리에서 일어나고
그 자리엔 문서가 없다. 그러니 다음 세션은 이 문서를 읽는 것으로 끝내지 말고 §6 에 **두 개를
더 얹어라**:

- **§0 을 재는 그물이 없다.** 형태는 이미 있다 — 말귀 비교셋 64문항(T5 60 / OpenClaw 55).
  거기에 **목적 달성** 축을 세운다: *사용자가 물은 사실이 답에 있는가.*
  `직접 보세요` · `제 범위 밖입니다` · `알려주시면` 으로 끝나는 답은 **실패로 떨어져야 한다.**
  그래야 문서가 못 잡는 것을 기계가 잡는다.
- **라이브가 관문이 아니다.** 오늘 진짜 결함은 **전부 라이브에서만** 드러났다(단위 초록 · 라이브 빨강 ×2).
  §4 는 "할 수 있다"이지 "해야 한다"가 아니다. 슬라이스 종결 조건에 라이브 1회를 넣어라.

## 3. 오늘 찾아낸 본질 — 도구 사용 프로세스

`오늘 한국 증시 상황은 어때?` 에 T5가 손을 세 번 썼는데 **세 번 다 질의 문구만** 바꿨다
(`장중` → `마감` → 날짜 붙이기). *"코스피 숫자를 얻었나"* 는 한 번도 안 물었다.

같은 질문을 나(Claude Code)에게 돌려 재 보니:

| | 나 | T5 |
|---|---|---|
| 검색 결과 | **목록을 보고 출처를 고른다** | 첫 결과를 읽는다 |
| 검색 요약 | 스니펫에 숫자가 있으면 쓴다 | *"스니펫으로 답하지 않는다"* 계약에 막힘 |
| 시작 시점 | **무엇이 '답'인지 먼저 안다** | 정하지 않는다 |
| 막혔을 때 | **출처**를 바꾼다 | **질의 문구**를 바꾼다 |

집행 형태는 `src/kernel/l1-intent/task-context.js` 의 `도구쓰는순서` —
`currentRequest` 옆, **모든 손이 지나는 자리**다. 웹 전용이 아니다.

```
① 무엇을 얻으면 답이 되는지 먼저 정한다
② 결과가 그것을 줬는지 대조한다
③ 못 얻었으면 질의를 바꾸지 말고 출처를 바꾼다
④ 끝내야 하면 무엇을 못 얻었는지 말한다(사용자에게 떠넘기지 않는다)
```

**커널은 "답이 됐나"를 판정하지 않는다** — 그건 내용 판정이고 심문의 부활이다(절대원칙 8).
커널의 몫은 목적을 잃지 않게 하는 것까지고, 판단은 모델이 한다.

## 4. 라이브를 직접 돌리는 법 (이거 찾는 데 오래 걸렸다)

```bash
cd /Users/jyp/Developer/t5-p-op
kill $(ps -eo pid,command | grep "surface/server.js" | grep -v grep | awk '{print $1}'); sleep 2
T5_FACTS_UNFILTERED=1 nohup node src/surface/server.js > /tmp/t5.log 2>&1 &
```

신분은 **쿠키 한 길**로만 받는다(`src/surface/local-surface.js`). 토큰은 오너 설치본 안에 있고
**읽지 말고 그대로 흘려보낸다**:

```bash
TOK=$(node -e "console.log(require(require('os').homedir()+'/.local/state/gpao-t5/sessions/install.json').token)")
SID=$(curl -s -X POST http://localhost:4173/sessions -H 'content-type: application/json' \
  -H "cookie: t5_surface=$TOK" -d '{}' | node -e "let s='';process.stdin.on('data',d=>s+=d).on('end',()=>console.log(JSON.parse(s).id))")
curl -s -m 400 -X POST http://localhost:4173/turn -H 'content-type: application/json' \
  -H "cookie: t5_surface=$TOK" -d "{\"sessionId\":\"$SID\",\"text\":\"오늘 한국 증시 상황 알려줘\"}"
```

응답의 `turnExchange[].data` 가 **모델이 실제로 받은 재료**다. 여기를 봐야 원인이 보인다 —
수집기 단위 검사는 전부 초록인데 라이브가 빨간 경우가 오늘만 두 번이었다.

주의: `redactSensitiveResult` 는 `runTurn` **뒤**에 돈다. 저장·표시용 마스킹이고
모델은 원문을 본다(내가 한 번 반대로 읽고 틀렸다).

## 6. 다음 순서 (내 권고)

1. **(다) 돌연변이 복구** — 5분. 빨간 채로 두지 않는다.
2. **(나) `blocked` 경로에도 다음 수단** — 막혔을 때야말로 다음 수가 필요하다.
3. **`web.search` 를 손으로 분리 (S8 ③)** — (가)의 답이 여기 있다.
   지금 `web.collect` 는 `request: '찾을 것(검색어) 또는 읽을 주소'` **한 칸에 둘이 섞여** 있고,
   검색하면 자동으로 첫 결과를 읽는다. **모델이 "후보만 보여 줘"를 부를 수 없다.**
   내가 하는 방식(목록을 보고 출처를 고른다)을 T5가 못 하는 이유가 이것이다.
4. **S8 ①② 계약 슬롯** — 오너가 좌표를 줬다(§7). 지금 `web-search.js` 는 슬롯이 아니라
   **이음매**다: `const order = deps.providers ?? [duckduckgo, searxng, tavily]` 이고
   호출부가 `providers` 를 안 넘긴다. 즉 오너가 얼린 성공 문장
   *"`web-search.js` 를 한 글자도 안 고치고 네 번째가 붙는가"* 는 **오늘 기준 불합격**이다.
5. **S8 ④ `ask_user` 를 모델 도구로** — 슬롯과 독립. 단 계약에
   *"런타임 `clarify` 를 대체했고 질문 총량이 안 늘었다"* 를 박아라. 안 그러면 질문 수도꼭지가 된다.
