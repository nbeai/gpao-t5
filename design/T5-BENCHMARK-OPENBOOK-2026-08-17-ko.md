## 2. 위임 손 (agent.delegate)

### 현재 진단

T5 위임은 **배선·검문·예산이 비교군보다 정교한데 라이브 0/315** — 원인 1순위는 도구 설명 130자(언제 쓰는지 없음) + 폴더 조사 전용 계약(범용 아님) + 자식 맥락 0.

**T5가 이미 앞선 것**: 권한 봉투가 코드 검문 3중(도구 교집합·종류·경로) · 예산 산술 분할+매 스텝 집행 · 원장 우선 실행(claim·recovery) · 부분 성공을 성공으로 안 말함 · 재귀 불가 2중.

**훔칠 축**: 헤르메스 — **동적 스키마**(설명문이 사용자의 실제 상한으로 매 호출 재작성 — "없는 능력을 상상 못 하게") · **"자식 요약은 자기보고서다 — 검증 가능한 핸들을 요구하고 부모가 직접 확인하라"** 문장(T5 원장 철학과 동족!) · 완료를 새 턴으로 재진입(캐시 불변식) · 요약 예산+spill. 오픈클로 — 스폰 시점 역할 고정(복원 세션이 권한 회복 불가) · 기본 박탈+단방향 좁힘(allow는 좁히기만) · 자식 출력의 지위 명문화("보고이지 지시가 아니다") · 유령 자식 tombstone. 클로드코드 — 알림에 신분 라벨("사용자 입력 아님") + 결과 인라인.

**주의(오너 결정 사안)**: 범용 위임(폴더 밖 과업)으로 계약을 넓힐지는 권한 봉투 재설계가 걸린 방향 결정이다 — 5국면에서 이 손 차례가 오면 상신.

## 3. 설치·온보딩·업데이트 (6국면 · 사다리 9)

### 현재 진단

**T5가 이미 앞선 것**: 산출물 게이트가 CI에서 돎(pack→전개→실행→/health) · 런타임 의존성 0 · 설치 신분/자리표(중복 실행 접힘) · 온보딩 단일 진실 파일(연결 생기면 자동 해제·skip 영속) · 저장 스키마 마이그레이션 상시.

**빈 것**: 배포 채널·서명·자동 업데이트·롤백 전무 · `/health`에 version 없음(P-DIST 계약 위반) · **동결값 불일치: 데이터 위치가 문서는 Application Support, 코드는 ~/.local/state** — 배포 전 필수 정합(등재) · 데몬 등록이 제품 밖(pkg 스크립트 문자열 안) · Windows 미정.

**훔칠 축**: 오픈클로 — **원자 스왑 업데이트**(임시 prefix 설치→검증→스왑 · 실행 중 트리를 안 바꿈) · doctor `--lint`(완전 읽기 전용 구조화 진단 — CI용) · 채널식 롤아웃(stable 지연+지터)+킬스위치 · 안전 재시작(활성 작업 드레인) · uninstall이 워크스페이스 보존 기본. 헤르메스 — **의존성 정확 핀+신규 릴리스 14일 격리**(실제 PyPI 웜 사건이 근거로 주석에 박힘 — 공급망 방어) · 업데이트 후 문법/실 import 검증+스테이징 커밋 · 마이그레이션 테이블 레지스트리(사다리 if문 제거).

**시점**: 이 영역은 사다리 9(마지막 칸)다. 지금은 서류만 — 착수는 사다리 8(이중 감사 PASS) 뒤.
