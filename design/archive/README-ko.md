# design/archive — 구현이 끝난 슬라이스 명세

정리: 2026-08-06 · 오너 지시 · 47개 이동

## 이게 무엇인가

**여기 있는 것은 전부 "그때 무엇을 왜 그렇게 만들었나"의 근거다.** 대부분 머리에
`구현·라이브 검증 완료` 라고 스스로 적어 두었다.

`GPAO-T5-KERNEL-CONTRACT-2026-07-24-ko.md` 가 봉인 절마다 이 문서들을 근거로 인용한다
(§6.10 ← `P6-11`, §6.14 ← `P6-15`, §6.15 ← `P6-16` …). 그래서 **지우지 않았다.**
왜 그 계약이 그 모양인지 파려면 여기를 읽는다.

## 규칙 — 여기 것은 현재 사실이 아니다

```
✗  현재 상태·다음 할 일·열린 결함의 근거로 쓰지 마라
✓  "그때 왜 그렇게 정했나" 의 근거로만 읽어라
```

현재 사실은 세 자리에만 있다:

```
지금 진행 중인 계획   design/T5-AI-OS-TRANSITION-PLAN-2026-08-05-ko.md
열려 있는 결함        design/T5-FOLLOWUP-LEDGER-ko.md
지금 상태             git log
```

## 왜 옮겼나

`design/` 에 76개가 섞여 있었고, **어느 14개가 살아 있는지 구분할 방법이 없었다.**
그 상태에서 실제로 사고가 났다 — 세 사람이 같은 날 낡은 문장 넷을 현재 사실로 읽고
없는 벽 앞에서 멈췄다(구조 개발원칙 §2-D).

> **낡은 문서는 안 고친 것보다 나쁘다. 손댄 흔적이 없으니 최신으로 읽힌다.**

옮기는 기준은 사람이 고르지 않았다 — **경로로 참조되면 남기고, 아니면 옮겼다.**
그래서 링크가 하나도 안 깨졌다(이동 전후 대조 확인).

## 다시 꺼내는 법

`git mv design/archive/<파일> design/` 로 되돌린다. 다만 되돌리기 전에 물어라 —
**이 문서가 말하는 것이 지금도 참인가.** 아니면 꺼낼 것이 아니라 새로 적을 것이다.
