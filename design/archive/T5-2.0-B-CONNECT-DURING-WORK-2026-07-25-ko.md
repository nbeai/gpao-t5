# T5 2.0-B · 작업 중 필요한 도구 연결 (첫 슬라이스)

작성: 2026-07-25 · 상태: 구현·라이브 검증 완료, 깊은 감사 대기
정본: `T5-2.0-TOOLBOX-CONNECTION-CENTER-UX-REFERENCE` §7 Slice 2.0-B.

범위(작게): 작업 중 필요한 도구가 needs_auth/needs_connection이면 **채팅 흐름 안에서** "연결이 필요해요"
카드 → 도구함의 해당 도구 상세 열기 → **실제 연결은 아직 안 함**, 연결 준비/설정 안내까지만.
실제 OAuth/토큰 저장은 후속.

## 핵심 기준 대응

| 기준 | 구현 |
| --- | --- |
| 죽은 버튼 금지 | 카드의 "연결 화면 열기"는 실제로 도구함을 그 도구에 포커스해 연다. 상세엔 준비 안내 텍스트만(가짜 '연결하기' 버튼 없음) |
| UI 상태 = runtime 상태 | 연결 필요 판정은 실제 SelfState status(needs_auth/needs_connection)에서만. 연결됨(토큰 있음)이면 카드 안 뜸 |
| pending context 유지 | connectionNeeded에 원래 요청(requestText) 보존 + 세션 activeGoal 유지 → "연결되면 이어서 진행할게요" |

## 흐름

```
사용자: 슬랙에 …올려줘   (SLACK_BOT_TOKEN 없음 → slack.post needs_connection)
T5(reply): 아직 실행 준비가 안 됐어요 + [연결이 필요해요 카드]
카드: "슬랙 게시 연결이 필요해요 / 연결되면 이어서 진행할게요" [연결 화면 열기][나중에]
→ 연결 화면 열기 → 도구함이 '슬랙 게시'에 포커스·상세 확장
상세: 연결/실행/승인 축 + "연결이 준비되면 이어서 쓸 수 있어요. (실제 연결은 곧 지원돼요.)"
```

## 구현

- **backend** `turn.js executePlan`: 이미 있는 `plan.blockedTools`(필요하지만 실행 불가) 중 연결/자격 문제
  (needs_auth/needs_connection)인 첫 도구를 `connectionNeeded {toolId, label, requestText}`로 구조화. 완전 차단
  (빨강)은 연결로 안 풀리므로 제외. 원래 요청 보존.
- **projection** `toolbox-view.js`: 실행 준비 안 된 도구에 `connectHint`(정직한 준비 안내). 실행 가능 도구엔 없음.
- **frontend**: 채팅 안 `renderConnectionNeeded` 카드 → `openToolbox(focusId)`가 패널을 열고 그 도구 카드를
  확장·강조·스크롤. 상세에 connectHint 렌더. 죽은 버튼 없음.

## 테스트 (4, 총 168)

미연결 슬랙 요청 → connectionNeeded(원래 작업 보존) · 연결됨(토큰)이면 안내 없음·승인 경로 · 일반 작업
안내 없음 · 도구함 미실행 도구 connectHint / 실행 가능 도구엔 없음.

반대 테스트: liveDeps가 토큰을 무시(항상 미연결)하면 "연결됨" 테스트 실패 → UI=runtime 자격 반영이 실제로
게이트함을 확인.

## 라이브 검증(브라우저)

미연결 슬랙 요청 → 채팅에 "슬랙 게시 연결이 필요해요" 카드 → "연결 화면 열기" → 도구함 슬랙 게시 포커스·
상세 확장·연결 준비 안내. `hasDeadConnectBtn:false` 확인. slack 노랑(실제 sender needs_auth와 일치).
