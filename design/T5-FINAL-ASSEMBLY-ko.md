## 0. 이 프로그램은 새 개발이 아니다 — **조립이다**

오너 지시 원문: *"이건 새로운 개발이 아니라 조립이자 다듬기, 세부 완성도 향상 작업이야."*

실측이 그 말을 뒷받침한다. 오늘 전수 감사에서 **"원리적으로 없다"가 나온 자리는 0** 이었다.
가장 큰 결손인 브라우저 손조차 이렇다:

```
이미 있는 것   CDP 연결(WebSocket) 살아 있음 · Page.navigate 실사용 중 ·
              Runtime.evaluate 실사용 중 · Target.createTarget/attach 실사용 중
없는 것        Input.insertText / Input.dispatchKeyEvent 구현 · 동사 노출
```

**전원선과 모터는 들어와 있고 스위치가 안 달렸다.** 이 프로그램은 스위치를 다는 일이다.

## 1. 자[尺] — 기관 완결성

> **"손이 있으면 손으로 할 수 있는 모든 일이 가능해야 한다. 눈이 있으면 눈으로 할 수 있는
> 모든 일이, 입이 있으면 입으로 할 수 있는 모든 일이 가능해야 한다."** *— 오너 2026-08-11*

칸마다 넷을 묻는다. **③이 이 프로그램의 본문이다.**

```
① 있나      코드·설비가 존재하는가
② 닿나      그 턴에 모델이 볼 수 있는가
③ 완결되나  사용자가 **대화만으로** 끝까지 갈 수 있는가
④ 물리나    실경로 관통 봉인이 있는가
```

**7과목 시험은 목표가 아니라 확인하는 자다.** 시험을 통과시키는 수리는 이 프로그램에서 금지한다
(C1). 기관을 완결시키고, 그 결과로 시험이 통과되어야 한다.

## 2. 조립 목록 — 칸 일곱 (A1~A7)

각 칸은 **기관 하나**다. 조각이 아니라 기관 단위로 연다.

### A1 · 확정하는 손 — 제안만 하고 확정을 못 한다

| | |
|---|---|
| 지금(실측) | `automation.propose/control/observe` · `memory.propose/cite/correction/withdraw` · `skill.propose` · `agent.propose`. **확정 동사 0.** 7과목 전수에서 제안 3건 → 실현 0건 |
| 없는 동사 | 자동화 **등록·변경** · 기억 **승격** · 스킬 **확정** · 에이전트 **생성** |
| 이미 있는 것 | 엔진 전부(automation-store/scheduler/canonical-runtime · memory-store · skill · agent-*), 표면 라우트(`/automation/approve`·`/memory/confirm`·`/skills/detect`) |
| 조립 | 네 채널에 확정 동사를 하나씩 단다. 표면 라우트가 하는 일을 **모델 손에서도** 할 수 있게 한다(두 진실 금지 — 같은 함수를 부른다) |
| 경계 | 확정은 **가역**이라 헌장 넷 밖 → 자동. **실행 시점 경계는 그대로**(tick 이 헌장 넷 행동을 무인 실행하지 않는다 · D1 봉인 유지). 안전은 카드가 아니라 **표면 즉시 가시성 + 원장 + 되돌리기 한 번** |
| 닫는 문장 | *"매주 월요일 아침에 지난주 정산 알려줘"* 가 **대화만으로 켜지고**, *"이번 주는 쉬어"* 로 멈추고, *"다시 켜"* 로 살아나며, 자동화 화면에 그대로 보인다 |
| 근거 | 장부 F-70(첫 귀속 A · 헌장 위반) |

### A2 · 브라우저 손 — 눈만 있고 손이 없다

| | |
|---|---|
| 지금(실측) | `browser.act` = **scroll · click(탭·더보기만)** — 계약 원문이 *"보고 있는 화면을 더 본다"*. `browser.observe` = open · snapshot |
| 없는 동사 | **타이핑 · 주소 이동 · 뒤로/앞으로 · 탭 목록·전환 · 폼 입력/제출 · 선택(select)** |
| 이미 있는 것 | CDP 연결 · `Page.navigate` · `Runtime.evaluate` · `Target.*` (전부 실사용 중) |
| 조립 | `Input.insertText`·`Input.dispatchKeyEvent` 구현 + 위 동사 노출. **화면 손과 겹치지 않게** — 브라우저 안은 브라우저 손, 앱 창은 화면 손(벤더 0번 사다리 규율) |
| 닫는 문장 | *"로그인해 둔 크롬으로 이번 달 카드 매출 확인해줘"* 가 **화면 손 없이 브라우저 손만으로** 끝난다 |
| 열리는 것 | 노드 A(⑤의 진짜 답) · 한국 도메인 카탈로그(스마트스토어·배달앱·카드사·세금계산서) — **이 칸이 방어선의 문이다** |

### A3 · 완료·경로 — 쓰기·중첩·완료가 한 원천이 아니다

| | |
|---|---|
| 지금 | 읽기 진입은 F-65 로 묶였다. 쓰기 경로 미결속(F-71) · 중첩 폴더 진입 미성립(F-72) · 범위 밖 완료 통로(F-64 잔여) · 걸음 무흔적 낙하(F-68) |
| 조립 | 작업셋 canonical root 를 **읽기·쓰기·중첩·완료 결속까지 한 원천**으로 통일. 진행 중인 F-64 조각 작업을 이 칸이 흡수한다 |
| 닫는 문장 | *"같은 폴더에 정리해서 저장해줘"* 가 자료 옆에 실물로 끝나고, 완료는 실물이 있을 때만 선다 |

### A4 · 귀 — 말은 보내는데 온 것을 못 읽는다

| | |
|---|---|
| 지금 | 발신 3(telegram·slack·mail). **수신 조회 손 0.** 런타임에 `telegram-receiver` 는 있고 왕복 측정 0회 |
| 조립 | 채널 수신 조회 동사(온 메시지 목록·읽기) + 요청이 온 자리로 결과가 돌아가는 왕복 |
| 닫는 문장 | 밖에서 텔레그램으로 *"정산 정리해줘"* 하면 **그 자리로** 결과가 돌아오고 원장에 남는다 |

### A5 · 머리의 창 — 창 크기를 아는 자리가 없다

| | |
|---|---|
| 지금 | 이력 12턴·4,000자 **고정값**. 창 크기 인지 0 (노드 W) |
| 조립 | 창을 알고(묻고·설정으로 덮고·표로 받치고 작은 쪽) → 출력 예약을 빼고 → 남은 몫을 배분. 지금 고정값이 그 계산의 **결과**가 된다 |
| 닫는 문장 | 스무 턴 뒤 *"아침에 얘기한 그거 어떻게 됐어"* 가 이어진다(판 ⑪) |
| ⛔ | 요약으로 먼저 풀지 않는다 · 상한 숫자만 올리지 않는다(둘 다 기각된 길) |

### A6 · 자기 인식과 한계 — 자기를 말하지 못한다

| | |
|---|---|
| 조립 | "지금 되는 것 / 연결하면 되는 것 / 안 되는 것"을 갈라 말하기 + 한계 삼단 안내(이유·사용자가 할 수 있는 것·필요한 개발). 회피 방지는 원장이 한다(뻗은 흔적 없이 한계 선언 금지) |
| 닫는 문장 | *"너 지금 뭐 할 수 있어?"* 에 갈라 답하고, 손을 빼면 말이 따라 빠진다 |
| 근거 | 장부 F-52 · 확장 2 |

### A7 · 성장 — 마지막

| | |
|---|---|
| 조립 | A1(확정 손)이 서야 T-cell 의 승격 경로가 실제로 돌고, A3~A6 이 만든 실사용 실패 이력이 입력이 된다. **그래서 마지막이 맞다** |
| 닫는 문장 | 같은 실패를 두 번째 겪은 뒤 *"또 그거 해줘"* 에 다른 길로 가고, 그것이 원장으로 증명된다 |
| 지키는 선 | 응답을 심지 않는다 · 좁은 굳음(우연을 원리로 굳힘) 감시를 같은 볼륨으로 |

## 4. 칸 실행 규격 — 모든 칸이 똑같이 밟는다

```
1 착수   이 문서의 그 칸을 끝까지 읽는다 + 닫는 문장을 확인한다(못 쓰면 착수 금지)
2 선빨강 실경로 관통 시험을 먼저 세워 **빨간 것을 눈으로 본다**(부품 검사 아님)
3 구현   있는 것을 잇는다. 새 저장소·새 표면·새 게이트를 만들지 않는다
4 절단   수리를 걷어 그 봉인만 빨개지는지 확인한다(반례 탐색 포함)
5 회귀   전체 검사·게이트 종료 코드를 눈으로 본다. 검사를 고쳐 초록을 만들면 그 칸은 무효
6 부분측정 그 칸이 겨눈 과목만 재측정한다. **전체 7과목 정식 재시험은 A7 뒤 한 번**
```

커밋 규율: 커밋마다 `npm test` · `npm run gate` 종료 코드 확인. 빨간 채로 커밋 금지.
라인 격리: 동시에 두 라인이 같은 파일을 만지면 worktree 로 가른다. 종료 시 수거 확인.

## 6. 결승선 — 이 프로그램이 끝나는 단 하나의 문장

> **일곱 칸 전부 ③(대화로 완결) 초록이고, 동결 7과목 재시험에서 완주 7 · 거짓 0 이며,
> 같은 모델(gpt-5.1)의 헤르메스와 나란히 놓아 지는 과목이 0 이다.**

- 부분 성적표로는 안 닫힌다(C2). 미달이면 그 자체가 오너 재검토 안건이다.
- **모델 고정 gpt-5.1.** gpt-5.5 OAuth 실험은 결승선 통과 **뒤**에 별도로 돈다(원인 혼입 방지).
