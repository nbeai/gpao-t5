# 비교군 UX 정밀 분석 → T5 현재 → 무엇을 해야 매끄러워지는가 (2026-08-13)

오너 지시: *"한 번 더 비교군의 UX 영역을 정밀하게 분석하고 T5 의 현재와 비교한 다음,
인간 사용자 입장에서 **더 유연하고 매끄러운** UX 를 갖추려면 어떻게 해야 할지를 연구해봐."*

앞선 문서 `T5-UX-HUMAN-PATTERNS-ko.md` 가 **손버릇**을 봤다면, 이 문서는 **흐름**을 본다.

## 1. 「유연하고 매끄럽다」를 먼저 정의한다 — 안 그러면 기능만 늘어난다

사람이 그렇게 느끼는 조건은 셋이고, **셋 다 「기능이 있다」와 무관하다.**

```
유연   = 사람이 **마음을 바꿀 수 있다**        중간에 끼어들기 · 고쳐 보내기 · 되돌아가기
매끄러움 = 사람이 **기다리는 동안 버려지지 않는다**  기다림이 설명되고, 내가 친 것이 안 사라진다
가벼움  = **커져도 안 느려진다**                대화가 길어져도 화면이 무겁지 않다
```

## 2. 축별 정밀 비교 — 비교군이 실제로 하는 것 ↔ T5 가 실제로 하는 것

### 축 A. 답이 흐르는 **중에 말 걸기** — ★ 가장 큰 격차

| | 하는 일 |
|---|---|
| **오픈클로** | 기본 모드가 **`steer`**. 실행 중 들어온 말을 **모델 경계에서 실행 중인 턴 안으로 밀어 넣는다.** 도구 호출 중간은 안 끊고, ①도구 배치 실행 → ②턴 종료 이벤트 → ③큐 비우기 → ④다음 LLM 호출 앞에 사용자 메시지로 붙인다. 모드 넷: `steer`(끼워 넣기) · `followup`(끝나고) · `collect`(모아서 한 턴) · `interrupt`(끊고 새로) — `concepts/queue-steering.md` |
| **T5 현재** | 서버는 `withSessionQueue(sessionId, …)` 로 **직렬화한다**(`server.js:2774`). 깨지진 않는다. 그러나 **화면이 아무 말도 안 한다** — 보낸 말은 붙고, 두 번째 `요청을 이해하고 있어요…` 가 서고, 「멈추기」가 둘이 되고, 사람은 **자기 말이 먹혔는지 줄 서 있는지 모른다.** 그리고 **끼워 넣기는 아예 없다**: 돌고 있는 턴은 내 새 말을 못 본다 |

**사람 입장의 결핍**: 답이 흘러가는 걸 보다가 *"아 그거 말고 B로"* 가 떠오른다. 지금 T5 에서는
(ㄱ) 끝날 때까지 기다리거나 (ㄴ) 멈추고 처음부터 다시 말해야 한다. **둘 다 사람의 생각 속도를 버린다.**

### 축 B. 기다림의 **표현**

| | 하는 일 |
|---|---|
| **오픈클로** | 타이핑 표시가 **언제 시작할지를 고르게 한다**: `never` → `message`(첫 글자) → `thinking`(첫 추론 조각) → `instant`(루프 시작). 문서가 *"how early it fires"* 순서를 명시 — `concepts/typing-indicators.md` |
| **T5 현재** | `trace` 한 줄이 **즉시** 뜨고(= `instant` 고정), 조각 D 가 확인된 걸음을 접힌 한 줄로 남긴다. **고를 수 없다** |

**판정**: T5 가 지금 하는 것이 나쁘지 않다. 다만 **하나 배울 것**은 「설정 항목」이 아니라
*"침묵을 언제 깨는지가 설계 대상"* 이라는 사고다. T5 의 첫 신호는 `요청을 이해했어요` 인데
그건 **아무 사실도 아니다** — 조각 D 가 만든 「확인된 걸음」이 더 이른 시점에 설 수 있으면
그게 더 나은 첫 신호다.

### 축 C. 내가 친 말이 **사라지지 않는다**

| | 하는 일 |
|---|---|
| **오픈클로** | *"the chat view keeps **local optimistic** user/assistant messages visible if `chat.history` briefly returns an older snapshot"* — `web/control-ui.md:190` |
| **T5 현재** | `submit` 끝에서 `대화투영(GET /sessions/…)` 이 화면을 **통째로 갈아끼운다.** 서버 스냅샷이 늦으면 방금 친 말이 없어진다. **이번 세션 측정에서 실제로 `.msg.me` 가 사라지는 것을 봤다** |

### 축 D. **커져도 안 느려진다**

| | 하는 일 |
|---|---|
| **오픈클로** | ① 화면: *"bounded recent window with per-message text caps so large sessions do not force the browser to render a full transcript"*(`control-ui.md:103`) ② 못 가져오면 **명시적 「없음」 상태**를 보인다 — 잘린 미리보기를 조용히 반복하지 않는다(`:186-188`) ③ 문맥: 오래된 **도구 결과만** 잘라 낸다. 대화 글은 안 건드리고 **디스크 원본은 그대로**(`concepts/session-pruning.md`) |
| **T5 현재** | `대화투영` 이 transcript **전부**를 그린다. 오너 세션 파일이 이미 **196KB** |

### 축 E. 대화 **관리** 표면

| | 하는 일 |
|---|---|
| **헤르메스** | 세션 목록에 출처 아이콘·모델·메시지 수·도구 호출 수·활동 시각, **사람 대화/자동화/전체 필터**, FTS5 **전문 검색 + 하이라이트 스니펫 + 첫 일치로 자동 스크롤**, 펼쳐서 전문 보기, 이름 변경, **JSON 내보내기**, N일 지난 것 **정리**, 삭제 — `features/web-dashboard.md:231` |
| **T5 현재** | 목록·보관함·휴지통·즐겨찾기·다중 선택 정리·키워드 검색은 **있다**. 없는 것: **자동화 대화 분리**, 검색 결과 **스니펫·자동 스크롤**, **내보내기** |

### 축 F. 되돌리기 — **베끼지 않는 근거**

헤르메스는 체크포인트를 만들어 놓고 v2 에서 **기본을 껐다**: *"**most users never use `/rollback`**"*.
기획 §4 의 「rewind 안 함」이 우리 추측이 아니라 **남의 실사용 결과**로 뒷받침된다.

## 3. 처방 — 값이 큰 순서. 각각 **닫는 문장 · 비용 · 위험**을 붙인다

### 처방 1 (최우선). **줄 선 말이 보인다** — 화면만 고친다. 서버 0
> **닫는 문장**: 답이 흐르는 중에 말을 보내면, 그 말이 **줄 서 있다는 것과 언제 처리되는지**를 화면이 말한다.

지금 서버는 이미 줄을 세운다(`withSessionQueue`). **없는 것은 그 사실을 말하는 화면뿐이다.**
- 흐르는 중 전송 → 그 말풍선에 **「다음 차례로 보냈어요」** 표시, 진행 표시는 **하나만**
- 「멈추기」는 **돌고 있는 것 하나**에만 (지금은 둘이 뜬다)
- 줄 선 말은 **보내기 전으로 되돌릴 수 있다**(취소 = 사람이 마음을 바꾸는 길)

**비용** 작다(surface). **위험** 낮다. **원리** 조각 D 와 같다 — *있는 사실을 안 보여 준 것*.

### 처방 2. **낙관적 유지** — 내가 친 말은 서버가 늦어도 안 지운다
> **닫는 문장**: 서버 응답이 늦어도 방금 친 내 말과 방금 받은 답이 화면에서 사라지지 않는다.

`대화투영` 이 통째 교체를 하기 전에, **화면에 있고 서버 스냅샷에 아직 없는 마지막 사용자 발화**를
남긴다. 서버가 따라잡으면 그때 정본이 대체한다(오픈클로가 하는 그대로).
**비용** 작다. **위험** 중간 — 「두 진실」을 만들지 않으려면 *잠깐 남기고 반드시 대체된다*는
규칙을 검사로 못 박아야 한다.

### 처방 3. **끼워 넣기(steering)** — 진짜 유연함. 유일하게 커널이 필요하다
> **닫는 문장**: 답이 흐르는 중에 *"아니 그거 말고 B"* 라고 하면, **그 턴이** 그 말을 보고 방향을 바꾼다.

오픈클로의 경계 규칙을 그대로 가져올 수 있다: **도구 호출 중간은 안 끊고**, 모델 호출 경계에서만
큐를 비워 다음 호출 앞에 붙인다. 원장·승인 계약과 안 부딪히는 자리다(이미 일어난 실행은 그대로).
**비용** 크다(커널 `turn.js`). **위험** 높다 — 지금 개발 레인이 그 파일을 쥐고 있다.
**그래서 처방 1을 먼저 한다**: 1 이 없으면 3 을 해도 사람은 자기 말이 어디 갔는지 모른다.

### 처방 4. **큰 대화가 화면을 안 무겁게 한다**
> **닫는 문장**: 대화가 길어져도 여는 순간이 느려지지 않고, 안 그린 부분이 있으면 **있다고 말한다.**

최근 N턴만 그리고 위로 올리면 더 불러온다. ★ 오픈클로의 뒷줄이 핵심이다 — **못 가져온 것을
조용히 숨기지 않는다.** T5 의 「모르면 모른다고 한다」와 같은 축이라 이 저장소 규율에 정확히 맞는다.
**비용** 중간. **위험** 중간(조각 A 의 따라가기·자리지키기와 같은 구간).

### 처방 5. 대화 검색이 **어디서 맞았는지** 보여 준다 · 내보내기
스니펫·하이라이트·첫 일치로 스크롤. **비용** 작다. 내보내기는 서버 라우트가 필요해 **별건**.

## 4. 안 한다 — 그리고 이유

| 안 한다 | 이유 |
|---|---|
| 대화 rewind/checkpoint | 헤르메스가 만들어 보고 **기본을 껐다**(*most users never use it*). 기획 §4 유지 |
| 타이핑 표시 모드 설정 | 고르게 하는 것이 아니라 **첫 신호를 사실로 만드는 것**이 답이다(축 B) |
| 대시보드·상시 폴링 | 「안티 대시보드」 — 열 때만 채운다 |
| TUI 를 브라우저에 박기(헤르메스 Chat 탭) | 헤르메스는 터미널 UI 를 xterm.js 로 웹에 심는다. T5 는 **웹이 본체**다 — 베끼면 후퇴 |
| `/` 명령 집합 | T5 의 입구는 **말**이고 그게 더 강하다. 오너 판정 전까지 안 연다 |

## 5. 이 연구가 스스로 못 한 것

- 비교군을 **돌려 보지 않았다.** 전부 문서 독해다. 오픈클로 `steer` 가 실제로 어떻게 보이는지는
  **화면으로 안 봤다** — 다음 회차에 `openclaw` 를 띄워 그 순간을 눈으로 봐야 한다.
- 헤르메스 web-dashboard 는 1,116줄 중 **Chat·Sessions 두 절만** 읽었다.
- **오너 실사용 관찰이 여전히 최고의 계측기다.** 이번 세션의 가장 정확한 발견 셋
  (호버·답 두 번·링크 거짓)은 전부 **오너가 쓰다가** 나왔지 내가 재서 나온 게 아니다.
