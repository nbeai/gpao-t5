# T5 2.0-A · 상태 기반 도구함 (첫 슬라이스)

작성: 2026-07-25 · 상태: 구현·라이브 검증 완료, 깊은 감사 대기
정본: `T5-2.0-TOOLBOX-CONNECTION-CENTER-UX-REFERENCE`(오너 커밋 e444232) §7 Slice 2.0-A.

P6가 도구·웹·채널·자동화의 실제 구동 계약을 닫았다. 2.0-A는 그 **살아 있는 능력을 사용자가 발견·이해하는
읽기 전용 상태 표면**이다. 연결 실행(2.0-B)·개인용 도구(2.0-C)는 후속 — 이번엔 상태만, 죽은 버튼 없음.

## 구현

- **백엔드 투영** `src/surface/toolbox-view.js` `projectToolbox(selfState, descriptors)` — 순수 함수.
  실제 `buildSelfState(env).connectedTools`의 status를 descriptor(toolKind·needsApproval·sourcePolicy)와
  합쳐 **사용자 언어 카드**로. `GET /toolbox`가 이를 반환.
- **프론트** 사이드바 `연결`(기존 data-soon 플레이스홀더 → 실제 오프너). 우측 슬라이드 패널:
  검색 · 카테고리 그룹 · 상태 점 카드 · 클릭 시 상세 확장. 모바일 전체폭.

## 감사 기준(정본 §10) 대응

| 기준 | 구현 |
| --- | --- |
| §10.1 UI 상태 = 실제 runtime | 상태 점·문구가 `SelfState.connectedTools.status`에서만 온다(투영, 조작 0) |
| §10.2 설치됨/실행/승인 분리 | 카드에 connected·executable·needsApproval 세 축을 각각 표기 |
| §10.3 없는 도구 안 만듦 | 카드 수 = descriptor 수. connectedTools에 없으면 회색(비활성) |
| §10.4 전송은 승인 경계 표시 | send 도구에 "실행 전에 확인받아요" 배지 |
| §10.5 웹은 출처 원장 표시 | sourceLedgerRequired → "출처를 남겨요" 배지 |
| §10.6 일반 사용자 언어 | needs_auth→"연결이 필요해요" 등. 기술 용어(status enum·MCP·token·schema) 미노출(테스트로 강제) |
| §10.7 채팅 흐름 보존 | 첫 화면은 채팅. 도구함은 사이드바에서 여는 배후 표면 |
| §10.8 모바일 안전 | 720px 이하 전체폭 패널, 오버플로 없음(육안 확인) |

상태 점(§4.2): 초록=사용 가능 / 노랑=연결 필요 / 빨강=차단 / 회색=비활성.

## 테스트 (8)

status→점 매핑(실제 status에서) · 세 축 분리 · 출처 원장 표면화 · 승인 배지 · **기술 용어 미노출**(needs_auth/
MCP/token/schema 문자열 금지) · 없는 도구 안 만듦(카드=descriptor 수) · connectedTools 없으면 회색 ·
서버 GET /toolbox.

## 라이브 검증

`연결` 클릭 → 도구함 패널: 웹 자료 수집·로컬 파일(초록 사용 가능), **메일 발송(노랑 "연결이 필요해요")**,
슬랙 게시(초록). 실제 runtime과 일치(mail.send 인증 미준비 → 노랑). 카드 클릭 → 상세(연결/실행/승인 세 축).
검색 "메일" → 필터. 모바일 전체폭. 데스크톱·모바일 스크린샷 육안 확인.
