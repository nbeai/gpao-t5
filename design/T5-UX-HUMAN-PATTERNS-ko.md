# 인간의 손버릇에서 UX 를 짓는다 — 선행자 공부 (2026-08-13)

오너 지시: *"너는 인간의 행동을 모르잖아. 그러니 이미 범용화되고 잘 사용되고 있는 서비스들을
보면서 힌트를 얻고 흡수할 걸 흡수하면서 **다양한 인간의 직관적 행동과 결핍과 필요를 헤아려서**
유엑스를 구성해야 하는 거야."*

이 문서는 **기능 목록이 아니다.** 순서가 반대다 — 사람이 반사적으로 하는 짓을 먼저 적고,
선행자가 그 짓을 **어떻게 받았는지**를 적고, T5 가 그 자리에서 무엇을 하는지 대조한다.

---

## 0. 볼 수 있는 것과 못 보는 것 (짐작으로 메우지 않는다)

```
① 클로드코드(나 자신)     ★ 내부까지 아는 유일한 교재. 이번 공부의 본체
② T5                      읽을 수 있다
③ 오픈클로 · 헤르메스       **원문이 이 기계에 없다**(2026-08-13 확인).
                          기획서 §6 의 인용은 앞선 세션이 다른 자리에서 가져온 것이다.
                          여기서는 **그 인용문 밖으로 나가지 않는다** — 본 척하지 않는다
④ 그 밖의 서비스           웹이 필요하다. 안 봤다
```
③④ 를 채우려면 원문을 이 기계에 놓거나 웹을 열어야 한다. **그 전까지 ③④ 칸은 비워 둔다.**

---

## 1. 관통 발견 — 사람은 **기능**을 안 찾는다. **손이 가던 자리**로 간다

이번 세션에서 오너가 두 번 지적했고, 두 번 다 같은 뿌리였다.

```
"뭐가 변한 게 하나도 없는 것 같은데?"        ← 호버해야 보이는 복사 버튼
"대화 내용 아래에 아이콘 같은 걸로 있어야지"   ← 손이 가는 자리를 지목한 것
```
기능은 **있었다.** 못 찾은 게 아니라 **손이 가던 자리에 없었다.**
그리고 나는 바로 앞에서 「멈춤이 안 보인다」를 고쳐 놓고 같은 병을 새 자리에 다시 지었다.
**이것이 이 문서가 필요한 이유다** — 나는 기능이 존재하면 됐다고 느끼고, 사람은 손이 닿아야 됐다고 느낀다.

---

## 2. 사람의 손버릇 → 선행자가 받은 법 → T5

「짓」은 사람이 **배우지 않고도 하는 것**만 적는다.

| 사람이 반사적으로 하는 짓 | 클로드코드(나)가 받는 법 | T5 는 지금 | 판정 |
|---|---|---|---|
| **방금 한 말을 다시 쓰고 싶다** — 조금만 고쳐서 | 입력칸 `↑` 로 직전 입력이 올라온다(셸·챗 공통 관습) | **없다.** 다시 타이핑해야 한다 | **흡수**(아래 §3) |
| **읽으면서 만진다** — 답이 흐르는 동안 위로 올려 읽고 긁는다 | 출력 중에도 스크롤·선택이 산다 | 조각 A 가 닫음 | 닫힘 |
| **멈추고 싶다. 되돌리고 싶은 게 아니다** | `Esc` 로 중단, 한 말은 남는다 | 조각 B 가 Esc 를 이음 | 닫힘 |
| **지금 어디쯤인지 보고 싶다** — 오래 걸리면 | 할 일 목록이 눈앞에 있고 진행이 갱신된다 | 걸음이 접힌 한 줄(조각 D). **목록은 없다** | 보류(§4) |
| **말한 그 파일을 열고 싶다** | 경로가 클릭이다 | 파일 이름이 **글자**다 | 후보(§4) |
| **같은 걸 두 번 묻지 마라** | 같은 종류 승인을 기억한다 | 헌장 넷만 묻는다(이미 더 낫다) | 안 함 |
| **끌어다 놓는다 / 붙여넣는다** — 파일을 | 경로 붙여넣기·드롭이 통한다 | **없다** | 후보(§4) |
| **타이핑으로 찾는다** — 메뉴를 뒤지지 않는다 | `/` 로 명령이 뜬다 | `⌘K` 는 대화 찾기뿐 | 보류(§4) |
| **돌아가고 싶다** — 방금 보던 자리로 | 주소·뒤로가기 | 조각 G 가 닫음 | 닫힘 |

### 2-1. T5 가 이미 더 나은 자리 (베끼면 안 되는 것)

- **승인**: 나는 도구마다 묻는다. T5 는 헌장 넷에만 묻는다. **T5 가 옳다** — 베끼면 후퇴다.
- **원장**: 나는 무엇을 했는지 말로 요약한다. T5 는 **기계 사실**로 남긴다(조각 D 가 그걸 보이게 했다).

### 2-2. ⚠ 내가 교재로서 못 미치는 자리

나는 **터미널**에 산다. 오너는 **브라우저**에 산다. 그래서 내 답 중 상당수(`↑`·`/`·키 위주)는
그대로 옮기면 안 되고, **같은 결핍을 브라우저 관습으로** 옮겨야 한다. 이 구분을 놓치면
"클로드코드처럼" 만들다가 웹에서 아무도 안 쓰는 것을 만든다.

## 3. 이번에 흡수한 것 — `↑` 로 직전 발화 되부르기

**고른 이유**: 위 표에서 **결핍이 가장 크고 값이 가장 싼 칸**이다. 사람은 하루에도 몇 번씩
방금 한 말을 조금 고쳐 다시 보낸다. T5 에는 그 길이 **없었다** — 조각 B 의 「고쳐 다시 보내기」는
*지나간 말*에는 답을 줬지만, **입력칸에 선 사람**에게는 아무것도 안 줬다.

**닫는 문장**: 입력칸이 비어 있을 때 `↑` 를 누르면 내가 방금 보낸 말이 올라온다. 계속 누르면 더 거슬러 간다.

**규율**
- 입력칸에 **글이 있으면 안 가로챈다** — 커서를 위로 옮기려는 사람이 훨씬 많다
- 되부른 뒤 `↓` 로 되돌아오고, 맨 아래는 **원래 쓰던 글**이다(빼앗지 않는다)
- 새 서버 상태를 안 만든다. 화면이 이미 들고 있는 `.msg.me` 를 읽는다(두 벌 금지)

## 4. 후보로 남긴 것 — **안 만든 이유를 함께 적는다**

| 후보 | 왜 지금 안 하나 | 열리는 조건 |
|---|---|---|
| 파일 이름을 누르면 열린다 | 여는 주체가 화면이 아니라 **손**이다(`local.file`). 승인·경계가 걸린다 — UX 가 아니라 권한 설계 | 헌장 판정 먼저 |
| 끌어다 놓기 · 붙여넣기 | 서버에 받는 문이 있는지 **안 쟀다**. 없으면 새 라우트 = 새 표면 | 라우트 실측 |
| `/` 명령 | 명령 집합을 새로 만드는 일이다. 지금 T5 의 입구는 **말**이고 그게 더 강하다 | 오너 판정 |
| 「지금 어디쯤」 목록 | 커널이 이미 원장을 갖는다. 화면이 다시 계산하면 **두 진실**이 된다 | 커널이 걸음 목록을 내보내면 |

## 5. 다음 공부가 먼저 해야 할 일

1. **오픈클로·헤르메스 원문을 이 기계에 놓는다.** 지금은 기획서에 인용된 문장 밖으로 못 나간다.
2. **비교군을 「도구 목록」이 아니라 「사람이 어디서 막히나」로 뽑는다.** 기능표를 베끼면
   T5 가 T5 가 아니게 된다(기획 §4).
3. **오너 실사용 한 회차를 통째로 관찰한다.** 이번 세션의 가장 정확한 발견 둘(호버·답 두 번)은
   전부 **오너가 쓰다가** 나왔지 내가 재서 나온 게 아니다. **사용이 최고의 계측기다.**
