# 전수 걷기 — 화면을 하나씩 열고 버튼을 하나씩 세었다 (2026-08-13)

오너 질문: *"전체 페이지, 각 메뉴, 모든 기능들의 배치나 연결 면에서 자신 있어?"* → 그때 답은
**"아니오"** 였고, 그 근거는 **한 번도 전수로 열어 본 적이 없다**는 것이었다. 이 문서가 그 일이다.

**짐작이 아니라 실제 클릭이다.** 헤드리스 크롬이 사람과 같은 경로로 눌렀다
(`설정` 버튼 → 탭 버튼 하나씩). 대본은 `scratchpad/walk.mjs`.

---

| 화면 | 1180px 보이는 버튼 | 375px | 내용 |
|---|---|---|---|
| 대화(본화면) | 14 | **12** | — |
| 대화 찾기 | 15 | 15 | — |
| 상태(칩) | 14 | 14 | 연결·스킬·선호·기억 요약이 실제로 찬다 |
| 도구함 | 15 | 15 | — |
| 설정 · 모델 | 22 | 22 | 모델 연결 |

| 설정 · 도구와 연결 | 23 | 23 | — |

```
빈 화면(열었는데 아무것도 없는 것)   0 / 11
탭 버튼이 없어 못 연 곳              0 / 7
글자도 라벨도 없는 버튼              0

```
**「죽은 문」은 하나도 없었다.** 0개일 때 빈 목록 대신 **다음 행동**을 주는 것도 확인했다
(스킬·자동화 둘 다 — 기획 §6-2 헤르메스 흡수 항목이 실제로 서 있다).

## 2. 잡힌 문제 — 하나

```
「닫기」를 세 가지 말로 쓴다:  취소 · ✕ · 🔍 닫기
```
같은 뜻인데 화면마다 다른 말이다. **지움·되돌림·보냄 축은 깨끗했다**(각 2가지 이하).

## 3. ⚠ 자[尺]가 두 번 못 닿았다 — 남겨 둔다

- `--window-size=375` 를 줬는데 **실제 폭이 500** 이었다(맥 최소 창 너비). 그대로 적었으면
  **「모바일 측정 완료」가 거짓**이 될 뻔했다. CDP `Emulation.setDeviceMetricsOverride` 로
  강제해서 **진짜 375** 를 쟀다.
- 도구함은 진입 버튼을 못 찾아 `classList` 로 열었다 — **사람 경로가 아니다.** 설정 7탭은
  전부 사람 경로(버튼 클릭)로 갔다. 도구함 진입점은 **다음에 사람 경로로 다시 밟는다.**

## 4. 이 걷기가 **아직 못 본 것** (전수가 아니다)

```
승인 카드            헌장 넷이 뜨는 그 순간. **모델과 실제 위험 동작이 있어야 뜬다** — 못 만들었다
비밀 입력 · 능력 해소   서버가 그 상황을 만들어야 뜬다
기억 반영/철회 · 자동화 제안 · 패턴 후보 · 전달 실패 · 복구   같음
```
이 여덟은 **데이터가 있어야 서는 화면**이라 빈 격리 서버로는 못 띄운다.
**「안 봤다」로 남긴다** — 없는 것으로 적지 않는다(이번 세션에서 그 실수를 세 번 했다).
띄우려면 각 상황을 만드는 **고정물 대본**이 필요하고, 그게 다음 회차의 첫 일이다.
