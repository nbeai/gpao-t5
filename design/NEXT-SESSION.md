# 8. ⑧ 착수하면 바로 부를 것 — 에이전트

**소집을 건너뛰지 마라.** 이 세션에서도 검문이 실물을 잡았다: 성적표 관대화 3+1(§7-bc) ·

```

t5-map-keeper         착수 때 "지도의 어느 줄에서 나오나" — 지도 §12 갱신도 이 손
