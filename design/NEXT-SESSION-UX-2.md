## 4. ★★ 주의사항 — 이 세션이 **실제로 데인 것들**이다

### 4-1. 「없다」고 말하기 전에 **어디를 얼마나 뒤졌는지** 적어라
이 세션에서 **세 번 틀렸다.**
```
"오픈클로·헤르메스 원문이 이 기계에 없다"  → 있다. 아래 §5 에 경로가 있다
"웹이 필요하다(안 봤다)"                → WebSearch·WebFetch 를 부르면 된다
"링크를 누구에게 보낼 수 있다"            → 127.0.0.1 이다. 남에게 안 열린다
```
**「없다」는 「있다」보다 비싼 주장이다.**

### 4-2. 음성 결과가 나오면 **자를 먼저 의심하라** — 이 세션에서 다섯 번 자가 틀렸다
```
숨은 탭에서 requestAnimationFrame 이 아예 안 왔다 → 「이탈 0px 완벽」이 나올 뻔했다
--window-size 375 가 실제 500                  → 「모바일 완료」가 거짓이 될 뻔했다
온보딩 덮개가 Esc 를 먼저 먹었다                 → 제품이 맞고 내 대본이 틀렸다
가짜 complete 가 서버 기록을 안 남겨 발화가 사라졌다 → 대본의 성질이었다
템플릿 문자열 주석에 백틱을 써서 대본이 안 돌았다
검사가 **내가 쓴 주석까지 세어** 스스로 빨개졌다
```
**계측기 검증을 먼저 해라**(`ux-cdp.mjs` 의 `준비대기`, rAF 가 오는지 확인).

### 4-3. 화면 규율 — 어긴 것들
```
호버는 UX 가 아니다          오너: "뭐가 변한 게 하나도 없는 것 같은데?" → 기본 동작은
                            **말풍선 아래 늘 보이는 줄**. 호버는 진하게만
투명도로 숨기지 마라          쉬는 상태 .55 는 「호버해야 보인다」를 다시 만든 것이다
안 도는 것에 도는 표시 금지    `.trace::before` 뛰는 점은 「지금 일하는 중」이라는 뜻이다
죽은 버튼 대신 텍스트         못 하는 상황에서는 **버튼을 안 만든다**(감추는 게 아니라 안 만든다)
이름은 하는 일에 맞춘다       T5 는 답을 갈아치우지 못한다 → 「재생성」이 아니라 「같은 질문 다시」
```

### 4-4. 코드에서 **실제로 물린 함정 셋**
```
말풍선(.msg) 안에 아무것도 넣지 마라   조각 A 의 `겹쳐맞추기` 가 흐르는 동안 자식을 제자리
                                    맞춤한다 → 넣으면 지워지고 A 반대시험 ⑥ 이 깨진다.
                                    동작 줄은 **말풍선 밖**, 턴 상자 안이다
`.stopbtn` 은 button 이 아니라 div   `:disabled` 는 폼 요소에만 붙는다 → `:not(:disabled)` 는
                                    **늘 참**이다. 속성(`!b.disabled`)을 직접 봐라
접힘을 `display:` 로 이기지 마라      `.record .body.rows{display:flex}` 가 기본 `display:none`
                                    을 이겨 **기록이 늘 펼쳐져 있었다**. 코드 검사로는 못 잡는다
```

## 9. 2026-08-13 인수 결과 — 겸임 구현

- ①~⑤ 구현. 실제 Chrome 1180·375에서 숨은 8면, 닫기 한 말, 늦은 저장 유지, 최근 80개와 생략 고지, 검색 대목·원문 이동을 확인했다.
- 오너 실사용에서 잡힌 새 대화 중복은 직전 세션의 저장 수를 물려받은 회귀였고, 사용자 1·답 1 반대시험으로 닫았다.
- ⑥ Hermes Dashboard·Chat을 격리 상태로 실제 실행했다. OpenClaw Control UI도 격리 실행했으나 설치된 로컬판의 namespace mirror가 재귀해 빈 화면(`Maximum call stack size exceeded`)이었다.
- ⑦은 개발팀 확인 결과 현재 `turn.js` 소유 충돌은 없지만, 이 UX 병합 뒤 별도 제품 조각으로 연다. 이 구간은 Codex가 구현·검사를 겸했으므로 독립 감사가 필요하다.
