# P6-18 · 사용자 표면 통합 — Slice-1: Status Overview (조용한 단일 진입점)

작성: 2026-07-26 · 상태: 구현·라이브 검증 완료, 깊은 감사 대기.
근거: 헌법 §5.5(안티 대시보드 — 채팅 점유 금지), P6-14~17 감사 후속(누적된 "반드시 구분").
관련: [[gpao-t5-hermes-absorption-roadmap]], §6.13~6.18.

## 왜 (표면부터 만들지 않는다 — 이미 선 계약을 조용히 모은다)

P6-14~17에서 전달·승인·채널·검색·스킬·선호의 **내부 상태 계약**을 먼저 세웠다. 이제 사용자가 "지금 무슨
상태인지 / 무엇이 실제로 반영·가능한지"를 한눈에 보되, **상시 대시보드가 아니라 열 때만 보는 조용한 요약**으로
통합한다. 첫 슬라이스는 **읽기 전용 단일 진입점**(기존 "현재 상태 보기" 칩 확장) — 실행/승격 버튼 없음.

## 절대 원칙

- **안티 대시보드(§5.5)**: 상시 패널·폴링 없음. 칩을 열 때만 `/overview`를 1회 fetch. 닫으면 사라진다.
- **읽기 전용**: 요약만. 실행·승격·재전달 버튼은 각 흐름(승인 카드·전달 카드·스킬/선호 API)이 담당.
- **누적된 "반드시 구분"을 구조에 박는다**(감사 후속 총정리): 각 항목이 두 범주를 **별도 필드**로 낸다 —
  섞이지 않는다. 특히 **추정됨 ≠ 반영 중**(추정을 "T5가 나를 반영한다"처럼 보이게 금지).

## 계약 (`surface/overview.js`)

`buildOverview({channels, skills, userModel, deliveries})` — 이미 만든 projection 조합만(신규 상태 없음):
- `connections`: `ready`(실제 받을 수 있음) ↔ `notReady`(연결/로그인 필요) — §6.15 연결≠가능.
- `skills`: `active`(admitted) ↔ `recommended`(candidate/replay_required) — §6.17 추천≠활성.
- `preferences`: `reflected`(admitted 운영 선호) ↔ `inferred`(추정, 영향 0) — §6.18 추정≠반영.
- `deliveries`: `deliveredCount` ↔ `failed`(다시 보낼 수 있음) — §6.13 실패≠완료.

## 배선

- `GET /overview?sessionId=` — channels(projectChannels)·skills(skillStore)·userModel(projectUserModel)·
  deliveries(deliveryStore, **세션 스코프 §6.13** — sessionId 없으면 전달 비움) 조합.
- UI: 칩(`#chip`) 열 때 fetch → `renderOverview`가 statePanel에 4구역을 사용자 언어로. on(초록)=반영/활성/가능,
  off(호박)=추정/추천/필요/실패. 읽기 전용.

## 테스트 (4, 총 277)

buildOverview 각 항목 두 범주 분리(추정↔반영 안 섞임·미확인 선호는 반영 아님) · 빈 입력 안전 · `GET /overview`
스토어 조합 + **전달 sessionId 스코프**(다른 세션 제외) · sessionId 없으면 전달 미노출(유출 방지).

라이브(브라우저): 칩 열기 → 연결(받을 준비됨 텔레그램 / 연결 필요 슬랙 채널) · 스킬(활성 없음 / 추천 없음) ·
선호(**반영 중 "표로 정리해서 주세요" / 추정됨(반영 안 함) "아침에 활동적일 수도"**) · 전달(보냄 0건 / 실패 없음).
색 분리로 반영↔추정이 한눈에. 닫으면 사라짐(상시 패널 아님).

## 완료/미완료 (사용자 언어)

- **된 것**: 칩 하나로 "지금 무엇이 실제로 반영·가능한지"를 조용히 본다. T5가 **짐작한 것**과 **실제 반영 중인
  것**이, **추천된 스킬**과 **켜진 스킬**이, **연결됨**과 **받을 준비됨**이, **못 보낸 것**과 **보낸 것**이
  각각 다르게 보인다. 짐작을 "안다"로 착각하지 않게.
- **아직 아닌 것**: 각 항목에서 바로 조치(재전달·스킬 승인·선호 확인)로 잇는 액션(다음 슬라이스), 검색 결과
  "찾은 기억↔반영된 기억" 카드(검색 표면 슬라이스), 모바일 레이아웃 정밀화.
